# 场景演示建议口径（内部）

**用途：** 对照《原表公式与经验配量确认.md》中客户待确认项，给出 **POC / 场景演示** 我方建议勾选，便于内部对齐与 demo 实现。  
**不是**客户已确认结论；客户书面确认后以确认稿为准，再回写 Skill。  
**关联：** `原表公式与经验配量确认.md`（客户确认稿）。

---

## 一、演示要证明什么

客户要的是：用 AI **完成「本项目的每平米收口演算 → 输出报价单」全过程**，而不是：

```text
打开原表某条样例每平米收口 × 招标面积 = 报价
```

| 材料 | 在演示中的角色 |
| --- | --- |
| 原表「1平方大模组屏体核算」、常规产品报价单样例 | **规则与公式结构的参考**（怎么加总、支架随形态怎么写、写死常数怎么用） |
| 招标 PDF + 抄录 | **本项目**尺寸、数量、安装形态、点间距等输入 |
| 规格单价表 | **本项目**模组宽高、大件取价 |
| 核算口径表 | **本项目**辅材/包材 BOM、经演示约定可用的价目与经验参数（见下） |
| AI 计价 / 报价单岗产出 | **本项目**重算后的分项构成（等价于「写出本项目的每平米收口」）+ `报价单.md` |

因此：样例收口里的「1㎡ 模组数量 = 8」「常规电源数量 = 2」等，**不**作为「拿来乘面积就完事」的项目基准；模组块数由规格推算，其余按下面建议的规则由 AI 逐步算出或标待确认。

---

## 二、演示数据流（简图）

```text
招标抄录 ──┐
规格单价表 ─┼─→ AI 计价：按规则重算本项目量价分项
核算口径表 ─┘         （模组/箱体/辅材包材/…；缺则待确认或 question）
                      ↓
              本项目「每平米收口」式分项底稿（04-计价）
                      ↓
              报价单（全表头；仅需报价条目；写死常数按原表样例做法）
```

原表样例页：**对照用**，不代入项目面积做一次乘法代替上图。

## 三、待确认项 → 演示建议

下列编号与确认稿第七节一致。勾选为 **演示建议**。

### A. 模组数量

| 项 | 演示建议 | 说明 |
| --- | --- | --- |
| 原则 | 规格单价表模组宽高 + 招标尺寸/面积推算；不读原表手填「1㎡ 模组数量」 | 体现「AI 重算」而非抄样例密度 |
| **A1 除不尽** | **向下取整**到整数块再计价 | 例：82.4 → **82** 块；备注写明原商与取整规则 |
| **A2 不能整拼网格** | 与 A1 相同：先按面积÷单块面积得商，再 **向下取整**；备注「未按整拼网格重排」 | 整拼排版若客户日后要求，再改为人工给定块数 |

**例子：** 单块 0.125㎡，屏 10.3㎡ → 82.4 → 演示按 **82** 块 × 模组单价。

---

### B. 电源等经验数量

| 项 | 演示建议 | 说明 |
| --- | --- | --- |
| 原则 | 样例收口中的电源只数不作项目默认基准 | 与「不能样例×面积」一致 |
| **B1 定额放哪** | 演示阶段：在核算口径 **演示册** 中单独维护「演示用每平方米电源只数」（可参考原表样例改写，但标记为演示维护值）；正式环境改为成本书面确认的现行定额 | 演示要能跑通完整收口，故允许演示册有明确维护值 |
| **B2 未维护时** | **question** 请人给定每平方米只数或本套总只数 | 无维护值不编造 |
| **B3 总台数除不尽** | **向下取整** | 例：2 只/㎡ × 10.3㎡ = 20.6 → **20** 只 |

**演示时 AI 仍要写出：** 本项目电源分项（只数来源 = 演示维护值或 question 答复；算式；取整），作为「本项目每平米/整屏收口」的一部分，而不是只抄样例行号。

---

### C. 箱体

| 项 | 演示建议 | 说明 |
| --- | --- | --- |
| **C1 口径** | **元/㎡**（核算口径箱体价目综合单价进入本项目平方单价构成） | 对齐原表收口结构，便于演示「重算每平米收口」；规格表箱体行仅作物料核对 |
| **C2 元/㎡** | 屏面积（可带小数）× 箱体元/㎡，**不再对箱体台数取整** | 元/㎡ 口径下无「台数除不尽」问题 |
| **C3 物理台数** | 演示 **不启用** | 若客户确认改走物理台数，再单独立规则；除不尽时建议与模组一致：**向下取整** |

**例子：** 箱体综合单价 800 元/㎡，屏 10.3㎡ → 箱体金额 8240 元，写入本项目收口分项。

---

### D. 支架

| 项 | 演示建议 | 说明 |
| --- | --- | --- |
| 原则 | 按确认稿第四节「安装形态 → 数量写法 + 价目档」由 AI **按本项目长宽重算** | 参考样例公式，代入招标尺寸，不抄样例行的现成支架数量 |
| **D1 形态不清** | **question** 给出候选形态，人选一档后再算 | |
| **D2 是否沿用写法** | 演示 **沿用** 第四节表 | 客户改某一形态后再改 Skill |
| **D3 数量为小数** | **向下取整** | 与模组/电源演示规则一致 |
| **D4 单位套/平方** | 演示勾选确认稿 **「按价目单位字面 + 第四节数量公式」**：价目「套」→ 元/套×形态数量（悬臂/洞内等）；「平方」→ 综合单价×形态数量（服务区数量=面积即元/㎡×㎡；天棚/门架数量=长+2 沿用原表） | 对应确认项 D4 第一勾选；量纲冲突则 question |
| **D5 双幅×屏数** | 演示 **暂不 × 屏数**（仍按单幅公式），备注「双幅支架是否×屏数待客户确认」；若用户当场要定 → **question**（不× / ×屏数 / 其他） | 对应确认项 D5；不得 silently ×2 |
| **立柱/钢构** | 形态支架计入；招标「含立柱」钢构不并入综合价，合计「未计入钢构」列明；交安已供不计 | 不 question「是否含在支架行」 |
| **抱箍** | 有价目行按套 **另计**（不并进支架单价列）；无行则 0 + 备注未计；**04 与报价单同结构** | 勿笼统待确认；勿把抱箍揉进支架单价 |

**例子：** 招标天棚屏长 12m → 支架数量 = 12+2 = 14（不是样例里长 10m 时的 12）。双幅门架 10m → 演示暂填 12，备注待确认是否 ×2。

### E. 辅材 / 包材

| 项 | 演示建议 | 说明 |
| --- | --- | --- |
| 原则 | 核算口径 BOM 滚出元/㎡，再 × 本项目屏面积 | AI 写出汇总路径，体现收口中的辅材/包材项 |
| **E1 汇总格为空** | 按明细数量×单价依表内公式 **滚出** 后再用 | 与现计价 Skill 一致 |

### F. 写死常数与控制系统（工控机、接收卡、控制箱、1.03、比例等）

| 项 | 演示建议 | 说明 |
| --- | --- | --- |
| 总原则 | **全部沿用**原表常规产品报价单样例做法（含控制系统口径） | 演示少打断；常数与公式写在 skill |
| 工控机 | 沿用样例写死加总（如 `2580+200+200`）及同行引用方式 | |
| 接收卡数量 | 按安装形态经验式 **对本项目长宽重算**；除不尽时 **向下取整** | 公式写在 skill |
| 普通/点检接收卡合计 | 数量 × **69** / × **750** | 与原表一致 |
| 大屏线材 | 按形态经验式，代入本项目长/高 | 如天棚 `(长−10)×100` |
| 综合价格 | 相关项加总后 × **1.03** | 与原表一致 |
| 比例 / 综合报价 | 比例 **0.68**；综合报价 = 综合价格 ÷ 比例 | 与原表一致 |
| 报价单总价 | 三档 `Σ(综合报价 × 招标数量)`；未计入钢构单列 | 必出 |
| **F1 接收卡** | 数量按形态重算并向下取整；单价与综合链按上表沿用 | 不另做待确认 |
| **F2 控制系统** | **沿用**：一套产品一套控制系统；控制箱汇总作每套底数；门架 1.5–2 / 服务区形态加价；**每条需报价行都计**；04 与报价单数字一致 | 对应确认项 F2 第一勾选；演示册已补示意价 |
| **F3 「10 平方」行名** | 演示勾选 **直接当每套底数**（不 ÷10、不按面积缩放）；备注可写「汇总行名含 10 平方，按每套取用」 | 对应确认项 F3 第一勾选 |

**例子：**  
- 天棚屏长 12m、高 1m → 接收卡按形态公式用 12、1 重算后向下取整；普通接收卡合计 = 数量 × 69；再进入 ×1.03 与 ÷0.68。  
- 门架屏长 10m、高 2m，控制箱汇总 3018.75 → 控制系统 = 3018.75 + 100 + 500 = 3618.75 元/套（不是 3018.75÷10×面积）。

## 四、取整规则（演示统一）

凡演示中「数量须为整数」且商为小数时，默认：

**向下取整（floor）**，并在算式备注中写明：原始商、取整后值。

适用于：模组块数、电源总只数（在采用「每㎡只数×面积」时）、支架数量小数、接收卡数量。  
不适用于：已约定的元/㎡ × 面积金额（箱体元/㎡、辅材元/㎡等可保留面积小数）。

## 五、演示验收时看什么

1. 产出中能看到 **本项目** 的模组块数推算（宽高来自规格表，面积来自招标），而不是「样例 8 块/㎡ × 面积」一笔带过且无规格依据。  
2. 产出中有 **分项收口**（模组/箱体/电源/辅材/包材等），结构对齐原表每平米核算，数字是本项目重算结果。  
3. 报价单尺寸、支架数量、线材、接收卡数量等随 **本项目** 长宽/形态变化；工控机/69/750/1.03/0.68 等按原表样例做法套用。  
4. 不是整行拷贝原表样例报价单。  
5. 「停车位入口预告标志」等含嵌入式屏的行进需报价，并走嵌入式/信息发布路径（范围 skill）。
