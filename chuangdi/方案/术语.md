# 创迪情报板报价术语

本表解释情报板报价里的行业说法，以及客户两张表中的列名、表名。每条给出含义和出现位置。供应商名称、单价和物料长描述不在本表中。

两张表的位置：

- 价格表：`docs/材料成本.xlsx`。下文称「材料成本表」。整理后为 **规格单价表**（大件单价）。
- 核算表：`docs/大模组核算2026.06.16.xls`。下文称「核算表」。客户造价/应标**演算底稿**；整理后为 **核算口径表**（辅材 BOM + 每平米数量）。Agent 报价三件套 = 规格单价表 + 核算口径表 + 计价 skill。
- 招标文件：招标编号 ZTYTWLGS-2026-04。需求一览表在印页第 118–119 页，附件四《技术评分标准》在印页第 61 页。

同一事物在两张表里的叫法，写在条目末尾的「对照」。

## 一、产品与安装

| 说法 | 含义 | 出现位置 |
| --- | --- | --- |
| 情报板 | 创迪的产品。安装在高速公路上，用于发布可变信息的 LED 显示屏。门架、悬臂、洞内、服务区都是它的安装形态 | 会议纪要；招标文件包件 QBB，物资名称「情报板」 |
| 可变情报板 | 情报板在招标清单中的全称，前面通常带安装方式，如门架式、悬臂式 | 需求一览表第 118–119 页 |
| 可变信息标志 | 行业标准里对情报板的正式名称。核算表的屏体描述用这个说法，和「情报板」指同一类产品 | 核算表屏体行的产品名称。招标样例的物资名称用「可变情报板」 |
| 门架式 | 屏跨在车道上方的门架上。分单幅（跨一侧行车方向）和双幅（左右幅各一块，清单里写成「10×1 米×2 块」仍是 1 套） | 附件四「门架式可变情报板」；需求一览表第 3、4 行；核算表按门架收口 |
| 悬臂式 | 屏装在路侧立柱的悬臂上 | 附件四「悬臂式可变情报板」；需求一览表第 1 行；核算表有悬臂支架 |
| 附着交安门架 | 屏挂在交通安全设施已有的门架上。钢结构由交安单位提供，创迪只含屏和连接抱箍 | 需求一览表第 2 行。附件四没有这个逐字名称，方案按门架式归并并标明 |
| 隧道内拱顶 / 洞内屏 | 装在隧道拱顶的情报板。清单里常同时写控制箱和支架 | 需求一览表第 8 行；附件四「隧道内拱顶可变情报板」；核算表「洞内屏」 |
| 车道屏 | 装在收费车道或车道附近的情报板，仍是同一产品 | 核算表产品形态 |
| 服务区 / 信息发布 | 装在服务区、停车区，用于信息发布的情报板 | 需求一览表第 7 行；核算表「服务区」 |
| 嵌入式 | 显示屏嵌在标志板里，和整块门架屏不是同一规格键 | 附件四「信息发布可变情报板（嵌入式可变情报板）」；需求一览表第 6 行写「嵌入式 LED 显示屏」，名称并不相同 |
| 立柱 | 支撑屏或悬臂的柱。清单写「含立柱」时计入报价 | 需求一览表；核算表安装件 |
| 基础预埋件 | 浇在基础里的预埋件。样例清单多次写「不含基础预埋件」，报价不含 | 需求一览表规格型号列 |
| 抱箍 | 把屏或支架箍在门架、立柱上的连接件 | 需求一览表第 2、6 行；核算表工作表「安装抱箍和螺钉」 |
| 支架 | 洞内、悬臂或服务区使用的支撑结构。单悬臂支架本身不是屏 | 需求一览表第 5、8 行；核算表工作表「支架」 |
| 支座钢结构 | 信息发布屏自带的支座。与「交安提供的钢结构」不同，后者不计入创迪报价 | 需求一览表第 7 行 |
| 控制箱 | 洞内情报板配套的控制箱体 | 需求一览表第 8 行；核算表工作表「压铸铝控制箱」 |
| 新建 | 新建设施上的情报板。成本路径与改造不同，样例表未写规则 | 会议沟通，待核 |
| 改造 | 既有设施上更换或加装。成本路径待核 | 会议沟通，待核 |
| 显示面积 | 发光面的宽×高，清单里用米。模组数量按这个面积和单块模组尺寸来算 | 需求一览表，如 3.2×1.6 米、10×1 米、3.84×1.92 米 |
| 套 / 块 | 清单的计量单位。1 套双幅里可以有 2 块屏，不能把套数直接当成屏数 | 需求一览表单位列 |

## 二、显示参数

| 说法 | 含义 | 出现位置 |
| --- | --- | --- |
| 点间距 | 相邻像素中心的距离，单位毫米。招标附件四直接写毫米；材料成本表用 P 加数字表示同一概念，如 P31.25 即 31.25mm | 附件四；材料成本表「名称」列。对照：点间距 = 名称列的 P 值 |
| P 值 | 材料成本表里点间距的写法。P25 即点间距 25mm | 材料成本表「名称」列；核算表按 P10.416、P20.833、P25、P31.25 等分产品 |
| 像素 | 屏上的一个发光点。由红、绿、蓝灯珠按配比组成 | 附件四「像素点间距」「像素分辨率」 |
| 像素分辨率 | 每平方米的像素数量。附件四对信息发布屏写每平方米 15625。按正方形像素估算时，每米 125 点，点间距约 8mm。这个毫米数是换算，附件四没有写成点间距 | 附件四嵌入式条款。样例价格表的 P 值档中未见 8mm |
| 配比 | 一个像素里红、绿、蓝灯珠的颗数，写成 nRnGnB。2R1G 表示双基色，没有蓝灯；2R1G1B、1R1G1B 含蓝，用于全彩或黄白显示 | 材料成本表「配比」列；需求一览表第 8 行写「双基色 2R1G」。招标附件四不写配比，由企业默认 |
| 双基色 | 只用两种颜色（样例为红和绿）的显示方式 | 需求一览表第 8 行；对应配比 2R1G |
| 全彩 | 红绿蓝都有的显示方式。价格表里带 B 的配比属于这一类 | 材料成本表配比列中含 B 的行。附件四未使用这个词 |
| 亮度 | 屏的发光强度。附件四用 cd 或 cd/㎡，材料成本表用 CD/㎡，指同一类指标 | 附件四；材料成本表「亮度」列 |
| 色品坐标 | 颜色是否落在交通用黄色或黄白的允许范围 | 材料成本表「色品坐标」列，取值为满足交通国标的黄或黄白 |
| 交通国标 | 材料成本表用来约束色品的公路用颜色要求。具体标准号以创迪现行依据为准，样例单元格只写「满足交通国标」 | 材料成本表「色品坐标」列 |
| 防护等级 | 防尘防水能力。附件四对门架和悬臂写 IP65 | 附件四。两张表的列里没有这一项，选型时作为过滤条件 |
| 视认距离 | 驾驶员能看清内容的距离。分静态和动态 | 附件四隧道内拱顶条款 |

## 三、材料成本表

| 说法 | 含义 | 出现位置 |
| --- | --- | --- |
| 模组 | 拼成整屏的最小显示单元，自带灯珠、底壳和面罩。整屏由多块模组排列而成 | 材料成本表各模组价格表；核算表「模组数量」「模组价格合计」 |
| 模组尺寸 | 单块模组的外形，材料成本表「尺寸」列，如 250×250、320×160、250×500。用来把显示面积换算成模组块数 | 材料成本表「尺寸」列。250×500 单独成表 |
| 灯珠 | 模组上的发光二极管，按红、绿、蓝分别计数、分别计价 | 材料成本表「R数量」「G数量」「B数量」及对应单价列 |
| 灯珠合计 | 三种颜色的灯珠金额之和，尚未加上加工费和套件 | 材料成本表「灯珠合计」列 |
| 灯珠批次 | 同一点间距和配比下，灯珠供货批次不同，单价不同。材料成本表把两个批次放在同一工作表的左右两块 | 普通模组表、250×500 模组表的左右分块。具体批次代号不在本术语中列出 |
| 贴片 | 灯珠贴装在板面的工艺。套件表把部分点间距分成贴片和直插两行 | 材料成本表「套件」表的名称列 |
| 直插 | 灯珠引脚穿板的工艺，与贴片相对。同一点间距两种工艺的套件单价可以不同 | 材料成本表「套件」表 |
| 芯片 | 有两处，不要混用。一是灯珠芯片，材料成本表「芯片」列；二是驱动芯片，列名「聚积芯片」，工作表也按驱动芯片系列分开 | 材料成本表「芯片」列、「聚积芯片」列，以及按系列分设的模组价格表 |
| 灌胶 | 模组表面灌封胶。分单面和双面；整理后同属一行，含税单价分两列；核算模板的「灌胶」只用来选列 | 材料成本表「含税单价（单面灌胶）」「含税单价（双面灌胶）」；整理模版「含税单价_单面」「含税单价_双面」 |
| 加工费 | 模组加工的费用，按驱动芯片系列分列，加进含税单价 | 材料成本表加工费列。系数不在本术语中列出 |
| 套件 | 模组上除灯珠以外的结构件总成，由底壳、面罩、胶圈合成 | 材料成本表「套件」表；模组价格表中的「套件单价」列 |
| 底壳 | 模组背面的壳体 | 套件表「底壳单价」 |
| 面罩 | 模组正面的罩。套件表分数量、单价、小计 | 套件表「面罩」 |
| 胶圈 | 模组密封用的圈 | 套件表「胶圈单价」 |
| 含税单价 | 材料成本表给出的成品单价，已含税。单面灌胶和双面灌胶各一列。核算表引用的模组价格应对应其中一列 | 材料成本表。对照：核算表「模组价格」取这里的含税单价，两表没有公式链接，靠人工抄入 |
| 箱体单价 | 按箱体种类和外形列出的单价，尚未乘数量 | 材料成本表「箱体单价」表。对照：核算表「箱体」表使用这个单价做屏体加成 |
| 全密封 | 箱体背面封闭 | 箱体单价表备注 |
| 后开放 | 箱体背面打开，便于维护 | 箱体单价表备注 |
| 包边 | 箱体四周是否带包边。同一外形，含包边和不含包边是不同行 | 箱体单价表备注 |
| 压铸铝箱体 | 铝合金压铸的箱体，有洞内、后开放等变体 | 箱体单价表；核算表「屏体压铸铝」「压铸铝平方辅材」 |
| 铁箱体 | 钣金箱体，分门架、悬臂、洞内 | 箱体单价表的门架铁箱体、悬臂铁箱体、洞内铁箱体；核算表「屏体镀锌钢板」「铁箱平方辅材」 |

## 四、核算表

| 说法 | 含义 | 出现位置 |
| --- | --- | --- |
| 屏体 | 显示面本身，不含支架时需看该行是否另计安装。核算表把屏体按箱体材料分成压铸铝和镀锌钢板 | 工作表「大模组-屏体压铸铝」「大模组-屏体镀锌钢板」 |
| 平方单价 | 每平方米屏的价格，用来乘显示面积 | 核算表「平方单价」「1平方大模组屏体核算」 |
| 模组数量 | 一块屏上的模组块数，由显示面积和模组尺寸决定 | 核算表 |
| 模组价格合计 | 模组含税单价乘模组数量 | 核算表。单价来源见材料成本表「含税单价」 |
| 电源 | 给模组供电的电源。核算表按「常规电源数量」汇总 | 工作表「电源」 |
| 接收卡 | 把控制信号分到模组的卡。与点检卡可以共用安装板 | 核算表「接收卡数量」 |
| 点检 | 检测灯珠是否失效的功能。点检接收卡单独计价，并进入「含点检综合价格」 | 核算表「点检接收卡合计」「含点检综合报价」 |
| 含点检综合报价 | 屏体、电源、接收卡、点检和约定辅料收口后的报价 | 核算表 |
| 工控机 | 现场控制用的计算机，按屏的类型决定是否计入 | 核算表 |
| 辅材 / 辅料 | 线缆、端子、螺钉、扎带等。核算表不按颗展开 | 工作表「1压铸铝平方辅材」「1铁箱平方辅材」 |
| 1 平方米标准用量 | 辅料的计价口径。每平方米给一套标准用量，再乘面积。结果是估算 | 核算表辅材表。会议说明：Excel 里辅料是估算，BOM 里才是逐颗 |
| 大件 | 报价时按名录核对的主要物料，如模组、箱体、电源、接收卡。与辅料估算相对 | 会议与微信。大件单价在材料成本表，数量关系在核算表 |
| 包材 | 包装，如纸箱。核算表有包材合计 | 核算表 |
| 安装件 | 抱箍、几字安装件、螺钉配件的总称 | 工作表「安装抱箍和螺钉」。其中「几字安装件单价」「抱箍单价」「螺钉配件合计」分列 |
| 子项物料编码 | 核算表辅料行上接近 ERP 的物料编码和规格描述。有编码不等于已经按 BOM 逐颗展开，用量仍按平方米 | 核算表辅材行 |
| 标准用量 | 核算表为某一安装形态规定的单位用量，辅料和部分安装件都用它 | 核算表 |

## 五、系统与流程

| 说法 | 含义 | 出现位置 |
| --- | --- | --- |
| BOM | 物料清单。创迪的权威清单在金蝶云星空，层级比核算表细 | 微信：BOM 在 ERP。金蝶表单标识 `ENG_BOM` |
| 物料 | 金蝶里的物料主数据，含编码、名称、规格型号、禁用状态 | 金蝶表单标识 `BD_MATERIAL` |
| 金蝶云星空 | 创迪使用的 ERP。目前由人在界面上查 BOM，是否已开通 WebAPI 待核 | 微信 |
| WebAPI | 金蝶云星空的查询接口。登录后用单据查询读取物料和 BOM。本方案只读，不写回 | 金蝶产品接口。租户是否开通待核 |
| 采购价目表 | 采购单价所在的单据，通常不在 BOM 上。标识以创迪账套为准 | 待核。价格仍以本地材料成本表为报价来源 |
| 报价单 / 投标明细价格表 | 按设计院清单的行序、名称、单位、数量输出的价格表。结构随项目变，不用创迪内部核算表代替 | 招标文件要求按需求一览表提供投标明细价格表 |
| 投标人选型 | 招标书写了点间距和亮度，但没写配比、芯片、灌胶时，企业用默认行满足这些指标。结果上必须标明，不能写成招标原文 | 方案中的处置，不在客户原表列名里 |
| 自动采纳 | 点间距有同名出处、价格表唯一命中、数量关系清楚、大件核对一致（若已接金蝶）的行。其余行标出由人确认 | 会议接收标准：约 90% 可采纳，其余约 10% 人工确认 |
| 需求一览表 | 第五章供货要求中的设备清单，给出名称、规格、单位、数量 | 印页第 118 页起 |
| 附件四 | 技术评分标准。情报板的点间距、亮度、防护等级、视认距离写在这里 | 印页第 61 页，包件 QBB |
