# 大模组核算原表：计算规则与辅材口径分析

本文说明原表公式链，以及已采纳的 Agent「三件套」整理口径。

## 一、原表在算什么

源文件：`docs/大模组核算2026.06.16.xls`（10 个工作表）。

**定位：** 客户原来的 **造价/应标演算工作簿**（不是单纯的「应标记录表」，也不是第三份规格价目）。一册里叠了：辅材 BOM → 每平米收口 → 屏体清单样例。应标时人会在清单层改尺寸；可复用资产是 BOM 与公式骨架。

### 1.1 两层结构

| 层级 | 工作表 | 作用 |
| --- | --- | --- |
| 报价清单层 | `大模组-屏体压铸铝` / `大模组-屏体镀锌钢板` | 按安装形态×点间距列出「一套屏」样例；面积、平方单价、屏体合计 |
| 每平米收口层 | `1平方大模组屏体核算` | 给出 **1㎡ 屏单价（总计）**，供上层 `平方单价` 引用 |
| 零件价目 | `箱体` `电源` `支架` `安装抱箍和螺钉` `压铸铝控制箱` | 大件单价（与材料成本表无公式链接，靠人抄） |
| BOM 明细 | `1压铸铝平方辅材` `1铁箱平方辅材` | 螺钉/线材/包材等逐项；**汇总后再喂回 1㎡ 表的「辅材」「包材」列** |

### 1.2 核心公式（压铸铝 P10.416 示例）

**1㎡ 总计：**

```
总计 = 1㎡模组价格合计 + 箱体单价 + 电源合计
     + 安装支架(选配) + 安装抱箍和螺钉 + 包材 + 辅材
```

其中：

- `1㎡模组价格合计 = 1㎡模组数量 × 模组单价`
- `电源合计 = 常规电源数量 × 电源单价`
- **包材** ← `1压铸铝平方辅材!F60`
- **辅材** ← `1压铸铝平方辅材!F56 + 1压铸铝平方辅材!E80 + 20`

**屏体报价行：**

```
面积 = 长 × 高
平方单价 = 1平方大模组屏体核算!…总计
屏体合计 = 平方单价 × 面积 + 大屏线材费用
```

镀锌钢板路径改引用 `1铁箱平方辅材`（如辅材 `E58+20`，包材 `E63`）。

### 1.3 BOM 如何得到「每平米辅材」

| 单元格（压铸铝） | 含义 |
| --- | --- |
| F9:F55 等 | 逐项：数量 × 含税单价 → 行合计 |
| **F56** | 「总计1平方辅料」= `SUM(F9:F55)` |
| E63:E78 | 「10 平方整体共用辅料」用量 |
| **E80** | `E79/10` → 折成 1 平方 |
| F60 | 「包材总计」 |

路径：

```
逐项 BOM → 汇总成「1㎡辅料 / 1㎡包材」→ 写入 1㎡ 屏单价 → × 屏面积
```

**对外乘面积** 与 **对内用 BOM 滚出每平米数** 是两层；原表两层都有。

### 1.4 哪些固定、哪些会变

| 层次 | 是否固定 |
| --- | --- |
| 公式骨架 | 相对固定 |
| BOM 明细行 / 用量 / 小件单价 | **不固定**，成本岗维护 |
| 常数加价（如 +20） | 写在公式里，属业务参数 |
| 应标时 | 通常不重做 BOM，用已滚好的元/㎡ × 招标面积 |
| 屏体清单长宽 | 样例；招标以抄录为准 |

## 二、已采纳：Agent 三件套

| 输入 | 管什么 |
| --- | --- |
| **规格单价表** | 模组/灯珠/套件/箱体等**大件单价**（来自材料成本） |
| **核算口径表**（多表） | **辅材 BOM** + **每平米收口数量**；包材/辅材公式引用 BOM；大件单价格留空 |
| **计价 skill** | 公式骨架：大件取规格单价表；辅材/包材取 BOM 汇总再 × 面积 |

改进点（相对原客户两本互不链接）：大件单价只维护一处。

整理脚本：`poc/整理原表.py`。计价口径：`poc/skills/报价计价/SKILL.md`。POC **不再**用 `price.py` 一类程序另写一套金额算法。

## 三、表名

| 文件 | 含义 |
| --- | --- |
| **规格单价表.xlsx** | 材料成本整理稿：一行一规格的单价 |
| **核算口径表.xlsx** | 大模组核算整理稿：BOM + 数量口径，不是又一份模组价目 |

模版内「核算模板」工作表仍是安装形态默认选型；其中「每平方米辅料」须与 BOM 滚出值勾稽，不一致以 BOM 为准。
