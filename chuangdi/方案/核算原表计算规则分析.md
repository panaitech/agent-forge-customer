# 大模组核算原表：计算规则与辅材口径分析

本文说明原表公式链，以及 Agent「三件套」整理口径。  
源文件：`docs/大模组核算2026.06.16.xls`（公式以该文件为准）。

**定位：** 客户原来的 **造价/应标演算工作簿**。一册里叠了：零件价目 → 辅材 BOM → 每平米收口 → 屏体常规产品报价样例。  
**项目报价：** 以本册为**规则参考**；由 Agent 按招标 + 规格单价表 + 核算口径表 **重算本项目收口并出报价单**，不是「样例每平米收口 × 招标面积」。详见 [场景演示建议口径.md](场景演示建议口径.md)、[原表公式与经验配量确认.md](原表公式与经验配量确认.md)。

---

## 一、工作表分层

| 层级 | 工作表 | 作用 |
| --- | --- | --- |
| 报价清单层 | `大模组-屏体压铸铝` / `大模组-屏体镀锌钢板` | 常规产品报价单样例：面积、平方单价、屏体合计、支架、工控机、综合价/报价等 |
| 每平米收口层 | `1平方大模组屏体核算` | **1㎡ 总计**（样例中即报价单「平方单价」来源） |
| 零件价目 | `箱体` `电源` `支架` `安装抱箍和螺钉` | 为人维护单价；与材料成本表无公式链接 |
| 控制箱 BOM | `压铸铝控制箱` | 控制系统金额来源之一（整理稿未迁入） |
| 辅材 BOM | `1压铸铝平方辅材` `1铁箱平方辅材` | 逐项汇总后写入收口「辅材」「包材」 |

---

## 二、平方单价（收口「总计」）——七项

收口表头与总计（压铸铝样例行逻辑）：

```text
总计 = 1㎡模组价格合计 + 箱体单价 + 电源合计
     + 安装支架（选配）+ 安装抱箍和螺钉 + 包材 + 辅材
```

不能只用「包材 + 辅材」当作完整平方单价。

### 2.1 模组侧

| 项 | 原表 | 项目自动报价 |
| --- | --- | --- |
| 1㎡ 模组数量 | 手填（样例常为 8） | **不读样例**；由规格模组宽高推算每㎡块数 / 整屏块数（演示除不尽向下取整） |
| 模组单价 | 手填或空；人从材料成本抄 | 规格单价表合成含税单价 |
| 1㎡ 模组价格合计 | 数量 × 单价 | 同上 |

### 2.2 箱体

| 项 | 算法 |
| --- | --- |
| 工作表 `箱体` | 序号、名称、数量、单位（多为㎡）、箱体单价、配件单价、**综合单价**、备注 |
| 综合单价 | 箱体单价 + 配件单价 |
| 收口「箱体单价」 | 引用价目综合单价（按压铸铝 / 镀锌含或不含包边选行） |

整理稿迁入「箱体」页；平方单价用本册元/㎡。规格单价表「箱体单价」为物理 SKU，作物料核对。

### 2.3 电源

| 项 | 原表 | 项目自动报价 |
| --- | --- | --- |
| 工作表 `电源` | 规格、功率因素、温度、单价等 | 整理稿迁入；正式空价由成本维护 |
| 常规电源数量 | 手填（样例常为每㎡ 2） | 样例不作未确认默认；确认定额或演示维护值 / question |
| 电源合计 | 电源单价 × 常规电源数量 | 总只数若按每㎡×面积，演示除不尽向下取整 |

### 2.4 安装支架选配（收口内）

收口该列样例多为空；有值时为人填或引用。  
**报价单层支架**另算：支架数量 × 支架价目综合单价（随安装形态，见第三节）。

### 2.5 安装抱箍和螺钉

价目表分列抱箍/几字件/螺钉后加总；收口该列样例多为空。整理稿迁入价目页。

### 2.6 包材 / 辅材

| 路径 | 收口引用 |
| --- | --- |
| 压铸铝 | 包材 ← 辅材表包材总计；辅材 ← 1㎡辅料汇总 + 共用折1㎡ + 常数（如 +20） |
| 镀锌/铁箱 | 对应铁箱辅材汇总格 + 常数 |

明细：含税单价 × 实际数量 → 再汇总成元/㎡。

## 三、报价清单层（屏体表）

`大模组-屏体压铸铝` / `镀锌钢板` 为常规产品报价单样例。项目报价代入**本项目**长宽与形态，按同结构重算。

| 列 | 样例算法要点 |
| --- | --- |
| 面积 | 长 × 高 |
| 平方单价 | 引用每平米核算总计（项目侧由本项目收口重算结果填入） |
| 大屏线材费用 | 随形态，如天棚 `(长−10)×100` |
| 屏体合计 | 平方单价 × 面积 + 大屏线材 |
| 支架数量 | 随形态：天棚 `长+2`，悬臂 `=面积`，车道屏 `长×高` 等 |
| 支架单价 | 引用 `支架` 价目对应行综合单价 |
| 工控机 | 写死加总如 `2580+200+200`（演示沿用原表做法） |
| 控制系统 | 引用控制箱汇总或形态加价 |
| 接收卡数量 | 随形态的经验式（演示按本项目尺寸重算，除不尽向下取整） |
| 普通/点检接收卡合计 | 数量 × 69 / × 750（演示沿用） |
| 综合价格 | 相关项加总 × 1.03（演示沿用） |
| 比例 / 综合报价 | 比例样例 0.68；报价 = 综合价格 ÷ 比例（演示沿用） |

形态对照表见确认稿第四节、场景演示建议口径 D/F。

## 四、Agent 三件套与整理结果

| 输入 | 管什么 |
| --- | --- |
| **规格单价表** | 模组/灯珠/套件单价；物理箱 SKU（核对） |
| **核算口径表** | 辅材 BOM；每平米收口结构；箱体/电源/支架/抱箍价目 |
| **计价 / 报价单 skill** | 本项目重算规则、取整、形态支架、写死常数是否沿用 |

### 4.1 整理脚本迁入范围

`poc/整理原表.py` 迁入：

- `压铸铝辅材`、`铁箱辅材`  
- `每平米收口`（模组单价列清空；保留对箱体/电源及辅材的引用）  
- `箱体`、`电源`、`支架`、`安装抱箍和螺钉`  

不迁入：屏体清单样例页、`压铸铝控制箱`。

维护见 [核算口径表维护说明.md](核算口径表维护说明.md)。
