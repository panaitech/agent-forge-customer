**用途：** 和创迪成本/报价同事确认原表口径，便于后续自动报价按约定规则执行。  
**依据文件：** `docs/大模组核算2026.06.16.xls`（大模组核算原表）。  
**阅读说明：** 下文用业务名称指代，不使用表格列字母。「样例」指原表里的示范数据；项目报价以招标抄录 + 现行维护表为准。

## 一、四个说法

| 说法 | 含义 | 举例 |
| --- | --- | --- |
| **按模组规格从面积推算** | 由单块模组宽高得到「每平方米几块」，再乘屏面积得到整屏模组数 | 每平方米模组数量；整屏模组总数 |
| **人工经验填写** | 表里直接写数字或选型；数量不由模组尺寸或屏面积唯一确定 | 每平方米配几只电源；价目上的单价；样例屏的长、高 |
| **公式计算** | 由其它格子按固定运算得出 | 金额 = 数量 × 单价；平方单价合计 = 各项相加；面积 = 长 × 高 |
| **经验规则写成的公式** | 格子里是公式，写法随安装形态变化 | 天棚支架数量 = 长度 + 2；悬臂支架数量 = 面积 |

### 模组数量

- 每平方米配几块模组 ≈ `1 ÷ 单块模组面积`（单块面积 = 模组宽 × 高）。例：单块 0.5m × 0.25m = 0.125㎡ → 每平方米 8 块。  
- 整屏模组数 ≈ 每平方米块数 × 屏面积（或 屏面积 ÷ 单块模组面积）。  
- **自动报价取数：** 规格单价表中的模组宽、高 + 招标抄录的屏尺寸/面积。  
- 原表工作表「1平方大模组屏体核算」中的「1㎡ 模组数量」为历史手填样例（多为 8），不作自动报价取数来源。

### 电源、箱体、支架（原表怎么处理）

- **电源：** 原表在「1平方大模组屏体核算」中手填「常规电源数量」（样例多为每平方米 2 只），再 × 电源单价进入每平方米成本。  
- **箱体进平方单价：** 原表「箱体」价目单位为㎡，综合单价按 **元/㎡** 进入每平方米成本；不是先算「整屏几台物理箱」再折算。  
- **支架：** 在常规产品报价单中按 **安装形态** 用不同数量写法（见第四节），再 × 支架价目。  
- 金额汇总可用「平方单价 × 屏面积」或「数量 × 单价」；电源只数、支架套数的 **配法规则** 见经验定额或安装形态表，不是「只用屏面积 × 一个固定系数」这一种算法。

## 三、工作表「1平方大模组屏体核算」（每平方米成本构成）

原表中汇总「每一平方米」成本；「总计」被常规产品报价单引用为「平方单价」。  
该表含历史样例行；整理进核算口径表「每平米收口」时，**初始内容仍来自这些样例**。样例数字须经成本另行确认为「现行定额」后，方可作为自动报价默认取数；未确认前，对应项按「人工给定」或「待确认」处理。

### 3.1 表头里几列在哪

打开原表工作表 **「1平方大模组屏体核算」**，表头一行可见：

| 原表列名 | 样例 | 含义 |
| --- | --- | --- |
| 材料 | 如「压铸铝箱体不含包边…」 | 箱体材料/包边类型 |
| **高度屏体安装高度** | 如 `1m` | 该核算行对应的屏体安装高度描述（原表列名即此，字面较长） |
| **灯珠** | 如 `310F5` 换行后再写 `1R1G` | 灯珠批次/型号与配色（红绿等）；确认稿有时称「灯珠配色」，指这一列 |

| 常规电源数量 | 多为 `2` | 历史手填的每平方米电源只数 |

### 3.2 模组数量：原表写法 vs 自动报价取数

| 内容 | 说明 |

### 3.3 人工经验填写（选型与电源等）

| 内容 | 样例/现状 | 说明 |
| --- | --- | --- |
| 箱体材料描述 | 按行手写 | 决定引用哪一档箱体价、走哪条辅材表 |
| 高度屏体安装高度、灯珠 | 见 3.1 | |
| 常规电源数量 | 样例多为 2 | 每平方米电源只数（历史样例） |
| 模组单价 | 常为空 | 应标时从材料成本抄入；原表无自动链到材料成本册 |

### 3.4 公式计算（金额怎么加总）

| 内容 | 怎么算 |
| --- | --- |
| 1㎡ 模组价格合计 | 1㎡ 模组数量 × 模组单价 |
| 箱体单价（进入平方单价） | 引用「箱体」价目对应档综合单价 |
| 电源单价 | 引用「电源」价目某一规格行 |
| 电源合计 | 电源单价 × 常规电源数量（每平方米） |
| 包材 / 辅材 | 引用辅材表汇总（辅材公式中常有业务常数，如 +20） |
| **总计（平方单价）** | 模组合计 + 箱体单价 + 电源合计 + 安装支架选配 + 安装抱箍和螺钉 + 包材 + 辅材 |

### 4.2 随安装形态变化的经验规则

根据原表压铸铝常规产品报价单各形态首行整理（镀锌表形态划分同类）：

| 安装形态（原表名称） | 支架数量写法 | 支架单价取自 | 大屏线材费用（若有） | 接收卡数量 |
| --- | --- | --- | --- | --- |
| 天棚屏 | 长度 + 2 | 收费大棚吊装吊架 | （长度 − 10）× 100 | 与长、高相关的经验式 |
| 悬臂 | 等于面积 | 悬臂含走道支架 | 样例无 | 与长、高相关的经验式 |
| 门架1米 | 长度 + 2 | 路段1米高支撑架 | （长度 − 10）× 100 | 同天棚一类 |
| 门架1.5-2米 | 长度 + 2 | 路段2米高支撑架 | 随长度、高度变化的经验式 | 同左 |
| 车道屏1米 | 长 × 高 | 路段1㎡支撑架 | 样例无 | 与高度相关 |
| 车道屏1×2米 | 长 × 高 | 路段2㎡支撑架 | 样例无 | 与高度相关 |
| 车道屏2×2米 | 长 × 高 | 路段4㎡支撑架 | 样例无 | 与高度相关 |
| 洞内屏1×2米 | （长度 ÷ 2 + 1）× 1 | 洞内屏支架价目的一半（表内写法） | 样例无 | 与高度相关 |
| 小型情报板1.5×1.5m | 长度 + 1 | 路段1㎡支撑架 | 样例无 | 样例直接写 1 |
| 服务区 | 长 × 高 | 服务区支架 | 面积 × 50 | 与长、高相关的经验式 |

**工控机：** 样例有「2580+200+200」写死加总。  

**双幅 / 每套多块屏：** 上表支架数量公式按单块屏的长、高写入。清单为双幅（如「10×1 米×2 块」仍计 1 套）时，支架数量是否再 × 屏数，原表未单独写清 → 见确认项 **D5**。

**控制系统（原表「控制系统」列）：**  
原表多引用「压铸铝控制箱」BOM 汇总；部分形态再按长、高加价。整理后取核算口径工作表 **「控制箱」** 汇总，按 **每套产品一套控制系统** 计入（**不按屏面积再乘**）。长、高用本项目米数，仅用于下表形态加价。

| 安装形态 | 控制系统金额 |
| --- | --- |
| 天棚 / 悬臂 / 门架1米 / 车道 / 洞内 / 小型等 | 控制箱汇总 |
| 门架 1.5–2 米 | 汇总 + `(高 − 1)×100` + `(长 − 5)×100` |
| 服务区 | 汇总 + `(高 − 1)×300` + `(长 − 5)×200` |

原表汇总行名常写作「总计辅材和箱体 **10 平方**」——属历史命名；自动报价默认把该合计当作 **每套** 控制系统底数，见确认项 **F2 / F3**。

**子项 F2 — 控制系统（报价单「控制系统」列）怎么取？**

原则说明（请确认）：  
- **一套产品 = 一套控制系统**（按招标「数量」的套/块计套，**不按屏面积再乘**）。  
- 金额取核算口径「控制箱」BOM **汇总作为每套底数**；原表对部分形态另有长、高加价（加价不是「按平方计价」，只是按米数加减）。  
- 不同安装形态用不同公式，但都是在「每套底数」上加减，不是「每平方米控制系统」。

| 形态 | 原表写法（请确认是否沿用） |
| --- | --- |
| 多数形态（天棚、悬臂、门架1米、车道、洞内、小型等） | = 控制箱汇总 |
| 门架 1.5–2 米 | = 汇总 + `(高−1)×100` + `(长−5)×100` |
| 服务区 | = 汇总 + `(高−1)×300` + `(长−5)×200` |

**例子：** 门架屏长 10m、高 2m，控制箱汇总 3000 元 → 控制系统 = 3000 + (2−1)×100 + (10−5)×100 = 3600 元/套。

- [ ] **沿用**上表：汇总 + 门架 1.5–2 / 服务区形态加价；其余形态只用汇总；**每条需报价行都计**一套  
- [ ] **一律只用**控制箱汇总，不加形态加价；每条需报价行都计  
- [ ] 仅招标写明「含控制箱」的行才计控制系统，其余空或 0  
- [ ] 待确认 / 人工给定每套控制系统金额
