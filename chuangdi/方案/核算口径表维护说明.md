# 核算口径表维护说明

本文说明 `数据/核算口径表.xlsx`（及演示副本 `核算口径表-演示.xlsx`）由谁维护、改哪几张表、改什么、不要改什么。  
公式链背景见 [核算原表计算规则分析.md](核算原表计算规则分析.md)。

## 1. 这张表管什么

| 文件 | 用途 |
| --- | --- |
| `核算口径表.xlsx` | 正式整理稿：辅材 BOM + 每平米数量口径；大件单价列留空 |
| `核算口径表-演示.xlsx` | POC/演示：在正式结构上补了模拟小件价与收口示意单价，**不是客户成本** |

Agent 报价三件套：

1. **规格单价表**（大件单价）
2. **核算口径表**（本说明）
3. **计价 skill**（`poc/skills/报价计价`）

大模组核算原 xls 是造价/应标演算底稿，不随任务上传；日常维护以整理后的核算口径表为准。

## 2. 谁维护

| 角色 | 职责 |
| --- | --- |
| 成本维护人 | 改 BOM 明细用量/小件单价；必要时改「每平米收口」数量口径；改常数加价时同步 skill |
| 报价执行人 / Agent | **不改**本表；只读已维护好的汇总结果与数量口径 |
| 整理脚本 `poc/整理原表.py` | 从客户原 xls **重新生成**正式稿时会覆盖；手改前先备份 |

## 3. 工作表怎么改

### 3.1 压铸铝辅材 / 铁箱辅材（日常主战场）

| 可改 | 不要改 |
| --- | --- |
| 某一行的「含税单价」「实际数量」（或铁箱表对应数量列） | 汇总行上的公式（如压铸铝 `F56` 总计1平方辅料、`F60` 包材总计、`E80` 10㎡折1㎡；铁箱 `E58`、`E63`） |
| 按工艺增删辅料/包材明细行（改完后核对汇总公式的引用范围是否仍覆盖新行） | 把汇总格改成手填常数（除非明确废弃公式链） |

改完后在 Excel 中打开，确认：

- 汇总格数值变化；
- **每平米收口**中「辅材」「包材」列（公式引用 BOM）跟着变。

应标报价时一般 **不重做整张 BOM**，用已滚好的元/㎡ × 招标抄录面积。

### 3.2 每平米收口

| 列 | 维护方式 |
| --- | --- |
| 1㎡模组数量、常规电源数量 | 工艺或拼法变了才改；偏稳定经验口径 |
| 包材、辅材 | **不要手填**；公式引用辅材表汇总格 |
| 模组单价、箱体单价、电源单价 | **正式稿留空**——大件价只维护在规格单价表。演示稿可填示意数，不得当正式成本 |
| 总计 | 保留公式骨架；勿拆成与 BOM/数量无关的死数 |
| 常数加价（如辅材公式中的 `+20`） | 属业务参数；改表后同步计价 skill |

招标以抄录面积为准，不依赖原屏体清单样例长宽。

### 3.3 说明

只改文字说明时，保持与规格单价表、skill 的分工一致：大件价在规格单价表，小件摊销在本表 BOM。

## 4. 和规格单价表的边界

| 变更类型 | 改哪张表 |
| --- | --- |
| 模组/灯珠/套件/箱体涨价或换规格 | **规格单价表** |
| 螺钉、线材、包材等用量或小件价 | **核算口径表 BOM** |
| 1㎡ 要几块模组、几只电源 | **每平米收口**数量列 |
| 怎么乘面积、怎么取 BOM 汇总格 | **计价 skill** |

禁止在核算口径表正式稿里再抄一份模组/箱体单价，避免双源。

## 5. 公式骨架（相对固定）

压铸铝路径（示意）：

```text
逐项数量×单价 → F56（1㎡辅料）+ E80（共用折1㎡）+ 常数
包材 → F60
写入每平米收口「辅材」「包材」→ 报价时 × 面积 × 屏数 × 套数
```

铁箱路径汇总格不同（`E58`、`E63` 等），骨架同类。  
明细与常数会变；骨架不要轻易拆。

## 6. 演示副本

`核算口径表-演示.xlsx` 由 `poc/seed_demo.py` 从正式核算口径表复制并填入**模拟**小件价、收口示意单价，并**按公式骨架滚出**行合计与 1㎡ 辅料/包材汇总数值，便于 POC 跑通算式。  

- 演示数参考公开市场大致量级推演，**不是创迪采购价**。  
- 对外报价、客户确认，只用正式表 + 客户真实单价。  
- 正式稿汇总格多为公式；若从未用 Excel 打开计算，Agent 读文件会看到空——须在 Excel 中重算，或由维护人写入滚出值；演示稿由 `seed_demo` 直接写数值。  
- 重新生成演示稿：`python3 poc/seed_demo.py`（会覆盖演示 xlsx）。
