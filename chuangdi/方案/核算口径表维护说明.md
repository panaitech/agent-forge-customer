# 核算口径表维护说明

本文说明 `数据/核算口径表.xlsx`（及演示副本 `核算口径表-演示.xlsx`）由谁维护、改哪几张表、改什么、不要改什么。  
原表公式见 [核算原表计算规则分析.md](核算原表计算规则分析.md)。  
项目如何重算收口、演示建议见 [场景演示建议口径.md](场景演示建议口径.md)、[原表公式与经验配量确认.md](原表公式与经验配量确认.md)。

## 1. 这张表管什么

| 文件 | 用途 |
| --- | --- |
| `核算口径表.xlsx` | 正式整理稿：辅材 BOM、每平米收口**结构**、箱体/电源/支架/抱箍**价目**；模组单价列留空 |
| `核算口径表-演示.xlsx` | POC：补模拟小件价与价目示意、滚出可读汇总；**不是客户采购成本** |

Agent 报价三件套：

1. **规格单价表**（模组/灯珠/套件；物理箱 SKU 供物料核对）  
2. **核算口径表**（本说明）  
3. **计价 skill**

大模组核算原 xls 是造价底稿，不随任务上传。

### 1.1 项目报价怎么用本表（重要）

- **不是**把「每平米收口」某条样例 × 招标面积直接当报价。  
- Agent 按招标抄录 + 规格单价表 + 本表 BOM/价目/**经确认的经验参数**，**重算本项目**的每平米/整屏分项（04-计价），再出报价单。  
- 表内「1㎡ 模组数量」「常规电源数量」等样例位：须成本确认为现行定额后，方可作默认取数；未确认则 question 或待确认。模组块数正式路径以规格表宽高推算为准。

### 1.2 平方单价七项与本册

```text
总计 = 模组合计 + 箱体单价 + 电源合计
     + 安装支架(选配) + 安装抱箍和螺钉 + 包材 + 辅材
```

| 分项 | 本册 | 取数 |
| --- | --- | --- |
| 模组合计 | 收口有样例数量列；单价列正式空 | **块数**：规格宽高 + 招标面积（演示除不尽向下取整）；**单价**：规格单价表 |
| 箱体单价 | 有「箱体」价目（元/㎡） | 本册箱体综合单价；规格表箱体仅核对 |
| 电源合计 | 有「电源」价目；收口有数量样例列 | 单价取本册电源；只数取**已确认/演示维护**定额或 question |
| 安装支架 / 抱箍 | 有价目页；收口选配列常空 | 支架主路径在报价单层按安装形态；价目取本册 |
| 控制系统 | 有「控制箱」BOM | 报价单取本册控制箱汇总（每套）+ 形态加价（见 skill） |
| 包材 / 辅材 | BOM | 本册 BOM 滚出元/㎡ × 面积 |

## 2. 谁维护

| 角色 | 职责 |
| --- | --- |
| 成本维护人 | BOM 用量/小件价；箱体/电源/支架/抱箍/控制箱价目；确认后的电源等经验定额；改常数加价时同步 skill |
| 报价执行人 / Agent | **不改**本表；按 skill 重算本项目；缺价或不确认定额不编造 |
| `poc/整理原表.py` | 从原 xls **重新生成**正式稿会覆盖；手改前先备份 |

## 3. 工作表怎么改

### 3.1 压铸铝辅材 / 铁箱辅材

| 可改 | 不要改 |
| --- | --- |
| 「含税单价」「实际数量」等 | 汇总行公式骨架（除非明确改工艺引用范围） |
| 按工艺增删明细行（改后核汇总范围） | 无依据把手填常数顶替汇总公式 |

### 3.2 箱体 / 电源 / 支架 / 安装抱箍和螺钉 / 控制箱

| 可改 | 说明 |
| --- | --- |
| 各档单价、名称备注 | 正式稿空/0 由成本补全 |
| 综合单价 / 行合计公式 | 箱体等保持「本体 + 配件」；控制箱保持单价×数量再汇总 |

### 3.3 每平米收口

| 列 | 维护方式 |
| --- | --- |
| 包材、辅材 | 公式引用 BOM；不要手填顶替 |
| 模组单价 | 正式稿留空 |
| 箱体/电源单价 | 公式引用本册价目；正式空价时由成本补价目 |
| 1㎡ 模组数量、常规电源数量 | 样例结构位；现行定额须书面确认后再当默认 |
| 总计 | 保留七项加总骨架 |

### 3.4 说明页

与规格单价表、skill、场景演示建议口径保持一致。

## 4. 和规格单价表的边界

| 变更类型 | 改哪张表 |
| --- | --- |
| 模组/灯珠/套件涨价或换规格 | **规格单价表** |
| 物理箱 SKU（尺寸/密封/包边）核对用 | **规格单价表**「箱体单价」 |
| 平方单价用的箱体 **元/㎡** | **核算口径表「箱体」** |
| 电源/支架/抱箍/控制箱价目 | **核算口径表**对应页 |
| 螺钉、线材、包材等用量或小件价 | **核算口径表 BOM** |
| 怎么乘面积、取整、形态支架、写死常数、总价 | **计价 / 报价单 skill**（演示见场景演示建议口径） |

禁止在正式稿收口再抄一份模组单价。禁止把规格表物理箱价与本册元/㎡ 混成双源进同一平方单价而不加说明。

## 5. 公式骨架（辅材/包材）

压铸铝路径：

```text
逐项数量×单价 → 1㎡辅料汇总 + 共用折1㎡ + 常数(+20)
包材 → 包材总计
写入收口「辅材」「包材」→ 本项目报价时 × 面积 × 屏数 × 套数
```

铁箱路径骨架同类（汇总格位置见原表/读表记录）。

## 6. 演示副本

`核算口径表-演示.xlsx` 由 `poc/seed_demo.py` 生成：BOM 与价目示意价、滚出可读数；电源只数等标为演示维护示意。

- 重新生成：先 `python3 poc/整理原表.py`，再 `python3 poc/seed_demo.py`。  
- 正式稿汇总格若无 Excel 缓存，Agent 读空时按明细滚算（见计价 skill）。
