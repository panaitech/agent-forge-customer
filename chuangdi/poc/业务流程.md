# 创迪情报板报价怎么走（Agent Forge）

主路径是控制台协作「创迪-情报板报价」：**上传附件 → Agent 读招标与价表 → 各岗交付 → 正式报价单**。  
本地脚本只整理价表 / selfcheck，不是协作入口。

口径说明：[场景演示建议口径.md](../方案/场景演示建议口径.md)、[原表公式与经验配量确认.md](../方案/原表公式与经验配量确认.md)、[核算口径表维护说明.md](../方案/核算口径表维护说明.md)。

## 任务里放什么

| 内容 | 怎么给 |
| --- | --- |
| 招标书 PDF | 任务**附件**（解析岗通读自动抽取，不必人写页码） |
| 规格单价表、核算口径表（POC 可用 `*-演示.xlsx`） | 任务**附件** |
| 导出格式（可选） | 任务说明写明要 **Word** 和/或 **PDF**；不写则只出 Markdown 报价单 |
| 补充提示（可选） | 任务说明可补充产品范围或排除项 |

价表本机整理：`docs/` → `数据/`（`整理原表.py` / `seed_demo.py`），再上传附件。

## 协作岗位与交付物

| 顺序 | 岗 | 读什么 | 交付物 |
| --- | --- | --- | --- |
| 1 | 解析 | 通读招标 PDF | `01-解析.md` |
| 2 | 复核 | 对照 PDF 全面核对 | `02-复核.md` |
| 3 | 读表 | 规格单价表 + 核算口径表（BOM、价目、收口结构） | `03-读表.md` |
| 4 | 计价 | 按公式链 **重算本项目**量价分项（等价于写出本项目每平米/整屏收口） | `04-计价.md` |
| 5 | 物料核对 | 大件规格（规格表；非逐颗辅材） | `05-物料核对.md` |
| 6 | 正式报价单 | 上游 + 导出要求；仅需报价；常规产品全表头 | `报价单.md`；若要求则另交 docx/pdf |

产品范围见 Skill `chuangdi-quote-scope`（常规/定制同一套后续逻辑）。非本品名单留在 01/02，**不进**正式报价单。  
交付物用页码 + 招标序号 + 设备名称指代。

### 计价与报价口径（与演示建议对齐）

- **禁止**「原表/核算口径样例每平米收口 × 招标面积」代替重算。  
- **模组数量：** 规格表宽高 + 招标面积；演示除不尽 **向下取整**。  
- **箱体进平方单价：** 核算口径「箱体」**元/㎡**；规格表箱体作物料核对。  
- **电源等经验数量：** 用已确认或演示册维护值，否则 question；总只数除不尽演示向下取整。  
- **辅材/包材：** BOM 滚出元/㎡ × 本项目面积；汇总格空则按明细滚。  
- **支架 / 线材 / 接收卡 / 工控机 / ×1.03 / 比例 0.68：** 结构跟原表样例做法，尺寸用本项目；数量除不尽演示向下取整（见场景演示建议口径 F）。  
- 招标未给点间距：解析标「招标未给出」；计价 **question** 后再取模组价，备注「用户指定，非招标原文」。  
- Word/PDF：优先平台 Skill `docx`/`pdf`，不够则工作区写代码。

## 注入与跑一次

```bash
cd chuangdi/poc/scripts
python3 inject_chuangdi_quote.py --tenant '<租户>' --base http://127.0.0.1:4096
# 控制台选协作，上传招标 PDF 与两张表；若要 Word/PDF 在说明里写明
```

租户需安装预置 Skill `docx`、`pdf`。

本机价表：

```bash
python3 chuangdi/poc/整理原表.py
python3 chuangdi/poc/seed_demo.py
python3 chuangdi/poc/run.py --selfcheck
```
