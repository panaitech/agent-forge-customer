# 创迪情报板报价怎么走（Agent Forge）

主路径是控制台协作「创迪-情报板报价」：**上传附件 → Agent 读招标与价表 → 各岗交付 → 正式报价单**。  
本地脚本只整理价表 / selfcheck，不是协作入口。

## 任务里放什么

| 内容 | 怎么给 |
| --- | --- |
| 招标书 PDF | 任务**附件**（解析岗通读自动抽取，不必人写页码） |
| 规格单价表、核算口径表（可用 `*-演示.xlsx` 对照） | 任务**附件** |
| 导出格式（可选） | 任务说明写明要 **Word** 和/或 **PDF**；不写则只出 Markdown 报价单 |
| 补充提示（可选） | 任务说明可补充产品范围或排除项；没有也不影响开干 |

价表本机整理：`docs/` → `数据/`（`整理原表.py` / `seed_demo.py`），再上传附件。

## 协作岗位与交付物

| 顺序 | 岗 | 读什么 | 交付物 |
| --- | --- | --- | --- |
| 1 | 解析 | 通读招标 PDF，按销售报价所需字段抽取 | `01-解析.md` |
| 2 | 复核 | 对照 PDF **全面**核对解析输出（非只核一项） | `02-复核.md` |
| 3 | 读表 | 规格单价表 + 核算口径表（含辅材 BOM、每平米收口） | `03-读表.md` |
| 4 | 计价 | 三件套：大件价表 + BOM/收口 + **公式链** Skill | `04-计价.md` |
| 5 | 物料核对 | 大件规格（非逐颗辅材 BOM） | `05-物料核对.md` |
| 6 | 正式报价单 | 上游 + 导出要求 | `报价单.md`；若要求则另交 docx/pdf |

报价单行须与招标清单一一对应。演示价不得进正式栏。  
计价必须走公式链，辅材/包材来自核算口径 **BOM 汇总**（见 Skill `chuangdi-quote-price`）。  
Word/PDF：优先平台 Skill `docx`/`pdf`，不够则工作区写代码。

## 注入与跑一次

```bash
cd chuangdi/poc/scripts
python3 inject_chuangdi_quote.py --tenant '<租户>' --base http://127.0.0.1:4096
# 控制台选协作，上传招标 PDF 与两张表；若要 Word/PDF 在说明里写明
```

租户需安装预置 Skill `docx`、`pdf`。

本机价表校验（可选）：

```bash
python3 chuangdi/poc/整理原表.py
python3 chuangdi/poc/seed_demo.py
python3 chuangdi/poc/run.py --selfcheck
```
