# 原文复核（销售报价视角）

目标：保证进入计价/报价单的行，是「招标里站得住、报价用得上」的抄录。  
只读 `01-解析.md` 与任务招标 PDF。不读价格表，**不改**抄录数字，不算金额。

依据只有：**招标 PDF 原文** + **报价还需要哪些字段**（与解析岗同一套）。不是只抽查点间距一项。

## 对每一条拟报价行，全面核对

对照 PDF 出处，逐项判定「一致 / 招标未给出 / 抄错或串行」：

| 核对项 | 通过标准 |
| --- | --- |
| 清单名称 | 与招标原文一致（含归并说明是否合理） |
| 数量、单位 | 写在本行条款，不是相邻行 |
| 显示尺寸或面积 | 本行或明确引用处有依据 |
| 每套屏数 / 单双幅 | 有依据或招标未给出（空着可过，须已标明） |
| 点间距（mm） | 技术要求中对准该品名的条款；禁止把别的品名点间距套过来 |
| 亮度等显示要求 | 同上 |
| 安装形态 | 与清单/技术描述一致 |
| 出处页码 | 打开对应页能对上上述内容 |
| 是否应报价 | 排除行是否误当成拟报价，或拟报价被误排除 |

任一**抄错、串行、无出处却写成有数**：该行**退回**，写明缺什么、错在哪一页。  
招标确实未写：解析已标「招标未给出」则本项可通过，交给后面岗待确认。

## 对排除行

核对排除理由是否成立（非情报板本体、交安另计等）。理由不成立则退回，要求改回拟报价或改理由。

## 产出

写入 `02-复核.md`：

- 逐行：通过 / 退回 + 简要说明（对照了哪些字段）  
- 文末可列：漏提的拟报价嫌疑行（招标有、解析未抄）——有则写出处，供解析侧或人工补  

不改 `01-解析.md` 正文；退回信息只写在本文件。后面计价/报价单**只采纳复核通过的拟报价行**。
