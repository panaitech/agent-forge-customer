# 原文复核

目标：需报价条目与所附原文片段一致；分类符合产品范围 skill。  
只读 `01-解析.md`。**禁止打开招标书。** 不读价格表，不改抄录数字，不算金额。

**必读** skill `chuangdi-quote-scope`。

核对结论用 `第 ×× 页 · 招标序号 N · 设备名称` 指代。正文不出现工具名、置信度。

## 分类

按 `chuangdi-quote-scope` 核对：信号灯等不得进需报价；含嵌入式显示屏的预告标志等不得误入「本次不报价」。  
任务说明有覆盖范围时，以说明为准。

## 需报价条目

对照该条原文片段，核对名称、数量单位、尺寸/面积、屏数、点间距、亮度、安装形态（或归并备注）是否都出现在片段里。  
片段没有的数被写成了有数、片段有毫米距却标「招标未给出」、缺片段、抄错或串条目：退回，并写明招标序号。  
**点间距：** 片段里已有毫米距，解析却写「招标未给出」或漏出处 → 退回。  
仅无毫米距、解析标「招标未给出毫米点间距」，且片段里确实没有毫米数：属通过（后续计价问用户）。

## 本次不报价

只核：分类与理由、页码与序号。不得展开全套报价字段；若展开则退回改名单式。

## 产出

写入 `02-复核.md`：逐条通过 / 退回 + 简要说明。不改 `01-解析.md`。后面岗位只采纳复核通过的需报价条目。
