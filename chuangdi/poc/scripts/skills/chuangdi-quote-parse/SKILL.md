# 清单解析

目标：只把**情报板本体**抄全，供后面核对、算价、出报价单。  
只读招标 PDF。不读规格单价表，不读核算口径表。

通读招标书，自行定位设备/需求一览表与技术要求、技术评分标准。任务说明若有补充范围可参考；没有补充也必须解析。

## 哪些进「需报价」

仅情报板 / 可变信息标志 / 可变情报板 / 信息发布用 LED 显示屏**本体**（含悬臂式、门架式、隧道内、嵌入式情报板等，以及明确含嵌入式 LED 显示屏且需按屏报价的条目）。

对这些条目写全报价字段（见下节）。标题格式：

`第 ×× 页 · 招标序号 N · 设备名称（原文）`

## 哪些进「本次不报价」（只记名单，不抽报价字段）

下列及同类**不报情报板价**的条目：只写标题（页码 · 序号 · 名称）+ **一句排除理由**。  
**不要**再写显示尺寸、点间距、亮度、防护、安装形态等报价字段。

常见排除（举例，以当次招标为准）：

- 信号灯、雾灯、车道指示器、天棚信号灯  
- 疏散指示标志、紧急电话/横通道等**电光标志**（指示灯类，不是可变情报板）  
- 纯支架、立柱、门架、钢结构（交安另计或无屏体）  

数量若一览表有，可顺带写单位数量；其余字段一律不抄。

## 需报价条目要写什么

| 信息 | 为何需要 |
| --- | --- |
| 页码 + 招标序号 + 清单名称（原文） | 打开 PDF 对应页即可核对 |
| 数量、单位 | 算量 |
| 显示尺寸或面积 | 算模组/箱体数量 |
| 每套几块屏 / 单双幅 | 面积与块数 |
| 点间距（mm） | 选模组规格 |
| 亮度等显示要求 | 选规格 |
| 安装形态 | 箱体/辅材路径、是否计交安钢结构 |
| 防护等（若有） | 影响产品路径时写入 |

技术条件看整本招标（本条目规格 + 技术要求/评分标准中对准该品名的条款）：写明了就写数值并注页码；都没有写「招标未给出」。不猜测，不套用其他品名。  
点间距「招标未给出」是合法结果；不要为了凑字段自选价表档位。选型由后续计价岗问用户。

正文不出现工具名、参数名、置信度。

## 产出

写入 `01-解析.md`：

1. **需报价条目**：仅情报板本体，字段齐全。  
2. **本次不报价**：名单式（页码 · 序号 · 名称 + 理由），不展开报价字段。
