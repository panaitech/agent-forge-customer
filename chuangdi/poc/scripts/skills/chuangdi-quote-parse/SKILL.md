# 清单解析

目标：按产品范围判定后，把**需报价**条目抄全，供核对、算价、出报价单。  
只读招标 PDF。不读规格单价表，不读核算口径表。

**必读** skill `chuangdi-quote-scope`（哪些进需报价 / 本次不报价）。常规品与定制品同一套后续逻辑，解析不因「是否标准成行」排除。

通读招标书，自行定位设备/需求一览表与技术要求、技术评分标准。任务说明若有补充范围，以说明为准。

## 分类

1. 先按 `chuangdi-quote-scope` 判定每一行。  
2. **需报价**：写全报价字段（见下节）。标题：`第 ×× 页 · 招标序号 N · 设备名称（原文）`。  
3. **本次不报价**：只写标题（页码 · 序号 · 名称）+ **一句排除理由**；**不要**再写显示尺寸、点间距、亮度等报价字段。  
4. 范围含糊：写「范围待确认」并依赖后续 question；字段可暂列，备注待确认。

## 需报价条目要写什么

| 信息 | 为何需要 |
| --- | --- |
| 页码 + 招标序号 + 清单名称（原文） | 打开 PDF 对应页即可核对 |
| 数量、单位 | 算量 |
| 显示尺寸或面积 | 算模组/箱体数量 |
| 每套几块屏 / 单双幅 | 面积与块数 |
| 点间距（mm） | 选模组规格 |
| 亮度等显示要求 | 选规格 |
| 安装形态（或归并后的形态） | 箱体/辅材路径、支架规则 |
| 防护等（若有） | 影响产品路径时写入 |

技术条件看整本招标：写明了就写数值并注页码；都没有写「招标未给出」。不猜测。  
点间距「招标未给出」合法；不自选价表档位。

名称归并（如附着门架→门架式、含嵌入式屏的预告标志→嵌入式/信息发布）：在备注写归并关系，不把归并名写成招标原文。

正文不出现工具名、参数名、置信度。

## 产出

写入 `01-解析.md`：

1. **需报价条目**：字段齐全。  
2. **本次不报价**：名单式（页码 · 序号 · 名称 + 理由）。
