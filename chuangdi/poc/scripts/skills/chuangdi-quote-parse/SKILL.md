# 清单解析（销售报价视角）

目标：为后面计价、物料核对、正式报价单准备**够用且可对标招标**的行。只读招标 PDF。不读规格单价表，不读核算口径表。

通读招标书，自行定位工程量/设备清单与技术要求等章节。任务说明若有补充范围可参考；**没有补充也必须解析**。

## 报价要什么（必须尽量抽出）

站在情报板销售做报价，每一条**拟报价行**应尽量具备：

| 信息 | 为何需要 |
| --- | --- |
| 招标清单名称（原文） | 报价单与招标一一对应 |
| 数量、单位 | 算量与报价数量 |
| 显示尺寸或面积（宽×高或㎡） | 算模组/箱体数量 |
| 每套几块屏 / 单双幅 | 面积与块数 |
| 点间距（mm） | 选模组规格、取价 |
| 亮度等显示要求 | 选规格、核对价表条件 |
| 安装形态（门架/悬臂/隧道/嵌入等） | 箱体路径、辅材口径、排除交安钢结构 |
| 防护/户外室内等（若有） | 影响产品路径时写入 |
| 出处页码 | 复核与报价单追溯 |
| 是否归并名称 | 避免和相邻条款串数 |

招标未写的项：**留空**，注明「招标未给出」，禁止猜测补数、禁止套用相邻行。

## 还要分清

1. **拟报价**：情报板 / 可变信息标志 / LED 显示屏本体相关行。  
2. **排除不报价**：明显非本品（信号灯、雾灯等），或纯支架/立柱且明确由交安另计——排除行只记名称与理由。  
3. 各招标目录、附件编号、页码不同，以当次 PDF 为准。
