# 产品范围（需报价 / 本次不报价）

本 skill 只回答：**这一行要不要按情报板做报价字段与后续计价**。  
常规产品与定制品（非标尺寸/形态）**同一套**模组推算、收口分项、报价单表头逻辑；差别只在参数是否落在价表成行组合，不另开排除规则。

## 进「需报价」（情报板 / 可变 QBB 本体）

名称或技术描述属于下列之一，且需要按 **显示屏体** 计价：

| 类型 | 常见写法（举例） |
| --- | --- |
| 门架式 / 悬臂式 / 附着门架可变情报板 | 可变情报板、可变信息标志（情报板） |
| 隧道内拱顶可变情报板 | 洞内屏、拱顶情报板 |
| 车道屏、服务区/停车区信息发布 | 信息发布可变情报板、嵌入式可变情报板 |
| **含嵌入式可变显示屏的预告/诱导类** | 如「停车位入口预告标志」且原文写明 **含嵌入式显示屏 / LED 可变显示** |

对需报价条目：按解析 skill 抽全字段；形态按门架/悬臂/洞内/车道/服务区/嵌入式等归并，名称不完全一致时在备注写归并关系（不把归并写成招标原文）。

## 进「本次不报价」（只名单 + 理由）

| 类型 | 常见写法（举例） |
| --- | --- |
| 交通信号与诱导灯具 | 信号灯、天棚信号灯、雾灯、车道指示器 |
| 电光/疏散类标志 | 疏散指示、紧急电话标志等（指示灯类，非可变情报板屏体） |
| 弱电其他系统 | 火灾报警、视频监控、紧急电话主机、广播等（非屏体） |
| 纯结构件 | 纯立柱、门架、钢结构、收费门架（无情报板屏体）；交安已供钢结构不计价时屏体仍可需报价、结构排除 |
| 纯静态标志板 | 仅标志板/反光膜、**未**含可变/嵌入式显示屏 |

## 边界条

**停车位入口预告标志（及同类「××预告标志」）：**

- 招标写明 **含嵌入式显示屏 / 可变显示 / LED 屏** → **需报价**（按嵌入式/信息发布类路径；备注「含嵌入式屏，归并信息发布/嵌入式」）。  
- 仅静态标志、无显示屏表述 → **本次不报价**（理由：静态标志，非可变情报板）。  
- 表述含糊 → 解析标「范围待确认」并 **question**；未答复前不进计价金额。

包件名含 QBB / 情报板不自动等于每一行都报价；仍按上表逐行判定。

## 任务说明覆盖

任务说明若写明「本次包含/排除××」：以任务说明为准，并在 01 备注引用说明原文。

## 与解析 / 复核

- 解析：先按本 skill 分类，再写需报价字段或名单。  
- 复核：核分类是否符合本 skill；误把信号灯等写入需报价、或把含嵌入式屏的预告标志漏出需报价 → 退回。
