# 报价计价（公式链 + BOM）

成本岗计价演算口径（产出 `04-计价.md`）。对外正式件见 skill `chuangdi-quote-sheet`。  
按本 skill 公式链执行；程序不另写金额算法。单价空着就留空，不补数，不挑最低价。

## 输入三件套

1. **规格单价表**（`规格单价表.xlsx`）：模组/灯珠/套件/箱体等大件单价。  
2. **核算口径表**（`核算口径表.xlsx`）：辅材 BOM（`压铸铝辅材` / `铁箱辅材`）+ 每平米收口。  
3. **本 skill**：公式链。BOM 明细与常数加价以表为准。

协作里「读表」只登记结构；算量算价与辅材在本岗按公式链 + BOM 做完并写出算式。  
只读本次任务附件工作簿；没有附件则退回。工作簿含「供应商」表则停止并退回。

## 读哪份文件

### 规格单价表

表头在第 4 行，数据从第 5 行起。写明文件名、工作表名、用了哪些列、模组有几行。不读「是否当前」「生效日期」。

### 核算口径表

| 工作表 | 用途 |
| --- | --- |
| 说明 | 分工说明 |
| 压铸铝辅材 | 逐项 BOM；汇总格滚出每平米辅材/包材 |
| 铁箱辅材 | 同上（铁箱/镀锌路径） |
| 每平米收口 | 按点间距×箱体材料核对 1㎡模组数量、电源数量；包材/辅材列公式引用 BOM |

任务附件里的规格单价表、核算口径表（文件名是否带「-演示」不论）一律按正式价表取数、算价。

## 怎么取大件价

1. 亮度、面积、屏数等以复核通过的抄录为准。  
2. **点间距**：抄录有毫米数则用抄录；抄录为「招标未给出」时，**先向用户提问再取模组价**（见下节），不得自选档位、不得空着跳过取价。  
3. 模组价格表一行一个规格；取行按点间距相同，可再按配比、尺寸、批次收窄。灌胶只决定取「含税单价_单面」或「含税单价_双面」。  
4. 命中一行才取价；命中多行列候选、金额留空；命中零行写未命中。  
5. 灯珠、加工费、套件、灌胶加价、箱体单价有空单元格时，金额留空并写明空列。  
6. 大件单价只取规格单价表（不用每平米收口表上的模组/箱体/电源单价列）。

## 招标未给出点间距时

复核通过的需报价条目若点间距为「招标未给出」（或等价表述）：

1. 用平台 **question** 工具按条目提问（可一次多题）：标明页码 · 招标序号 · 设备名称，请用户给出点间距（mm）。  
2. 选项可列规格单价表中已有档位（如 25 / 31.25）作候选；**不要默认代选**；允许用户自定义填写。  
3. 用户答复后，按该值取模组行并写算式；在 `04-计价` 该条写明：`点间距 = … mm（用户指定 / 投标人选型，非招标原文）`。  
4. 用户拒答或未答：该条模组金额留空，写「点间距待用户确认」，不猜测。

## 公式链（按序写进 04-计价）

1. **显示面积** = 宽 × 高（米）。  
2. **模组数量** = 显示面积 ÷ 单块模组面积 × 每套屏数 × 套数；除不尽则停下；双幅按抄录块数。  
3. **含税单价_单面** = 灯珠合计 + 加工费 + 套件单价；**含税单价_双面** = 单面 + 灌胶加价。  
4. 灯珠合计 = 各色数量 × 各色单价；套件合计 = 底壳 + 面罩数量 × 面罩单价 + 胶圈。  
5. **模组金额** = 模组数量 × 所取面别含税单价。  
6. **箱体数量/金额**按箱体外形同样处理；交安已提供的钢结构不计。  
7. 电源、接收卡：规格单价表无单价则只列数量。  
8. **辅材/包材**（下节）→ 每平米金额 × 面积 × 屏数 × 套数。  

### 辅材 / 包材（BOM → 元/㎡ → × 面积）

按表内标签与公式语义定位汇总格（表结构会变，以当次附件为准）：

1. **选表**：压铸铝 → `压铸铝辅材`；铁箱/镀锌 → `铁箱辅材`。  
2. **认结构**：明细为逐项 BOM；汇总区找「总计」「1平方辅料」「包材总计」「10㎡ 折 1㎡」等标签；常数加价以表内公式为准（压铸铝收口辅材常含 `+20`）。  
3. **汇总格读不出数时必须自己滚**（常见：单元格是公式、文件未经 Excel 计算，读到空）：  
   - **压铸铝**：行合计 = 含税单价 × 实际数量；`总计1平方辅料` = 明细行合计之和；`包材总计` 按表内公式（常为包材行合计 + 常数）；若有「10㎡ 折 1㎡」行一并计入。  
   - **铁箱**：先算 **价税合计 = 含税单价 × 实际数量**（该列常空，不能只看汇总格）；再按表内 `SUM` / ÷10 / +常数 滚出「1平方辅料单价」「包材总计」。  
   - 禁止因汇总格显示空就整条辅材/包材留空（明细有单价与数量时）。  
4. 在 `04-计价` 写明工作表名、行标签、读到或滚出的数值与算式；辅材须来源于 BOM（汇总格或按公式滚出）。  
5. 可与「每平米收口」辅材/包材列对照；该列若也是未计算公式则忽略，以 BOM 滚出为准；不一致则待确认。

### 与每平米收口核对

同点间距、同箱体材料在「每平米收口」有「1㎡模组数量」时，与按面积除出的每平米块数核对；不一致则待确认。
