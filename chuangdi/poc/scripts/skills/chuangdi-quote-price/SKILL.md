# 报价计价（本项目收口重算）

产出 `04-计价.md`：本项目每平米/整屏收口分项底稿。对外正式件见 `chuangdi-quote-sheet`。  
金额只运行本包 `scripts/calc.py`。禁止在思考里逐行乘除，禁止把脚本抄进工作区再改。

**禁止**「核算口径样例每平米收口 × 招标面积」代替重算。  
单价与 BOM 只取 `03-读表.md`。禁止打开表格文件，禁止去翻大模组核算原表。

## 输入

只读这三份，**禁止再打开招标书、规格单价表、核算口径表**：

1. `01-解析.md`：需报价字段与原文片段。  
2. `02-复核.md`：只采纳通过的条目。  
3. `03-读表.md`：规格与价目的结构化数字。03 没有的单价写「待确认，03 未登记」，禁止回表补洞。  

公式以本 skill 为准。见 03 写明「供应商表、已退回」则停止，不编价。

## 取整（统一）

数量须为整数且商为小数时：**向下取整**；算式备注写原始商与取整后值。  
适用于：模组块数、电源总只数（每㎡只数×面积时）、支架数量小数、接收卡数量。  
不适用于：元/㎡ × 面积（箱体、辅材、包材可保留面积小数）。

## 读哪一节（都在 03-读表.md）

| 03 中的节 | 用途 |
| --- | --- |
| 规格单价 · 模组 | 点间距、配比、宽高、灯珠/加工费/套件/灌胶与含税单价 |
| 压铸铝辅材 / 铁箱辅材 | BOM → 辅材/包材元/㎡；汇总格为「空」则按明细滚 |
| 箱体 | 综合单价（元/㎡）→ 进平方单价构成。不用规格表箱体单价算金额 |
| 电源 | 规格单价；每平方米只数看「每平米收口」的常规电源数量 |
| 支架 / 安装抱箍和螺钉 | 综合单价与单位（单位只作备注） |
| 控制箱 | 汇总 → 控制系统每套底数 |
| 每平米收口 | 只取已维护的常规电源数量；样例「1㎡模组数量」禁止当项目块数 |

## 模组

1. 亮度、面积、屏数、长高等以复核通过的抄录为准。  
2. **嵌入式 / 预告类：** 清单只给标志板外形、未给屏显尺寸 → 按外形整板计面积，备注「屏显尺寸未确认，暂按外形」。禁止为此 question。  
3. **点间距：**  
   - 抄录或招标技术条款（含名称归并后）已有**毫米**数 → **直接用**，备注招标出处页；**禁止**标「用户指定」、**禁止**再 question。  
   - 仅像素密度或全书无毫米距（解析标「招标未给出毫米点间距」）→ 调用 **question**。`options` 为 03 规格「点间距_mm」去重后的每一档，再加一项「暂不定档」。有密度时，与折算毫米最接近的现有档放第一项，label 写成「10 mm 档（建议）」，description 写价表组别和折算关系（如 15625/㎡ ≈ 8mm，价表无 8mm）。题干不罗列档位。不代选。同一密度的多条合成一道题。拒答或选暂不定档则模组金额留空；用户选定后备注「非招标原文」。  
4. **配比：** 招标已写（如 2R1G）→ 直接用。未写 → 取 03 该点距下标注的「默认」行，备注「招标未给出配比，取默认档 X，投标人选型」。03 只有一行则用那行，备注「招标未给出配比，价表仅一行」。不再为配比 question，避免整表模组金额留空。  
5. 命中规格行：点间距相同，可再按配比、尺寸、批次收窄。清单已写单面或双面则按所写取含税单价。**未写面别：用单面价，不加灌胶，禁止 question**，备注「清单未写面别，按单面」。  
6. 单块面积 = (模组宽_mm/1000)×(模组高_mm/1000)。  
7. 整屏模组块数 = 屏面积合计 ÷ 单块面积，再 **向下取整**（不能整拼网格时同此规则，备注「未按整拼网格重排」）。  
8. **禁止**使用每平米收口样例「1㎡模组数量」作为块数来源。  
9. 含税单价_单面 = 灯珠合计 + 加工费 + 套件；双面再加灌胶加价。单元格空则金额留空。  
10. 模组金额 = 块数 × 面别含税单价。

## 箱体（元/㎡）

1. 按箱体材料/包边命中核算口径「箱体」价目行，取 **综合单价（元/㎡）**。  
2. 箱体金额 = 综合单价 × 屏面积合计（面积可带小数，不对「台数」取整）。  
3. 规格单价表「箱体单价」本岗不用于平方单价金额；交安已提供的钢结构不计。  
4. 价目空则该分项待确认。

## 电源

1. 单价：核算口径「电源」价目，按规格命中一行。  
2. 每平方米只数：03 该点距「常规电源数量」有维护值则用该值。**没有维护值：按 2 只/㎡，禁止 question**，备注「该点距无维护值，按2只/㎡」。  
3. 总只数 = 每㎡只数 × 面积后 **向下取整**。只数与金额由脚本计算。

## 辅材 / 包材

1. 选表：压铸铝 → `压铸铝辅材`；铁箱/镀锌 → `铁箱辅材`。  
2. 汇总格为空（未计算的公式）时按明细滚：  
   - 压铸铝：行合计 = 含税单价×实际数量；再按「总计1平方辅料」「包材总计」「10㎡折1㎡」及表内常数（常有 +20）。  
   - 铁箱：先价税合计 = 含税单价×实际数量，再按表内 SUM/÷10/+常数滚元/㎡。  
3. 辅材金额 = 辅材元/㎡ × 面积合计；包材同理。写明工作表与标签。

## 支架 / 抱箍 / 钢构 / 控制系统（与报价单 skill 同口径）

支架**数量只按下面的形态公式**代入本条长、高。价目上的单位「套」或「平方」只抄进备注，**禁止**据此把数量改成 1 套、改成面积以外的算法，或在打回后换一套算法。单价取核算口径「支架」综合单价。数量为小数时向下取整，备注写原始商。

| 安装形态 | 支架数量 |
| --- | --- |
| 天棚屏、门架1米、门架1.5-2米 | 长 + 2 |
| 悬臂、车道屏、服务区 | 长 × 高 |
| 洞内屏 | (长 ÷ 2 + 1) × 1 |
| 小型情报板 | 长 + 1 |

形态对不上表：**question**，`options` 的 label 只列上表形态名，禁止写进题干代替选项。禁止自选形态后落笔。

- **支架永远按形态公式算**，只有「交安已供整套钢构」才把支架与抱箍写成 0（`steel: "provided"`），**禁止 question**。
- **含立柱、含支座、门架横梁、标志板本体、附着在既有立柱/预告标志立柱**：这些「本体」不并入综合价，填 `body` 字段写进「未计入钢构」清单，但**支架、抱箍仍按公式算**，禁止据此清支架。  
- **双幅 / 每套多块屏**：面积按块数计（脚本按 长×高×panels 算）。支架、接收卡、线材、抱箍、控制系统只用单幅长高，**不再 × 屏数，禁止 question**。备注「屏数已计入面积，数量按单幅公式」。  
- **抱箍**：每套 1 只，不乘块数、不乘面积。清单写明「含连接抱箍钢结构」或交安已供 → `hoop: "provided"`，抱箍为 0；有价目则按价，无价目 `hoop_price: null`。禁止把抱箍单价并进支架单价。  
- **灌胶**：清单已写单面或双面才按所写取价。未写则单面，禁止 question。  
- **控制系统（每套）：** 控制箱汇总作每套底数（行名含「10 平方」也不 ÷10、不按面积折）。门架 1.5–2 加 `(高−1)×100+(长−5)×100`；服务区加 `(高−1)×300+(长−5)×200`。由脚本统一算，禁止在思考里逐行算。  
- **线材、接收卡**：永远按形态公式由脚本算，不随钢构归属清零。  
- **只允许提问这两件**：全书没有毫米点间距；形态对不上表。问完把用户原话写入该条备注。其它口径按本节默认落笔，禁止再问。主管不会看到提问答复，所以答复必须写进 `04-计价.md`。

## 04 每条需报价必有分项

| 字段 | 要求 |
| --- | --- |
| 面积 | 脚本按 长×高×屏数 算，模型不填 |
| 模组（单块面积、块数含取整、单价、金额） | 有则填 |
| 箱体（元/㎡、金额） | 有则填 |
| 电源（只数来源、取整、单价、金额） | 有则填；否则待确认/已 question |
| 辅材元/㎡、辅材金额 | 有则填 |
| 包材元/㎡、包材金额 | 有则填 |
| **本项目平方单价构成 / 收口小计** | 已填七项能加则加；缺项标明待确认 |
| 支架数量与单价、支架合计 | **必预列**（供报价单原样抄） |
| 抱箍数量、抱箍单价、抱箍合计 | **必预列**三列（无则 0 +「未计」）；禁止揉进支架单价 |
| 控制系统（控制箱汇总±形态加价） | **必预列**（每套；供报价单原样抄） |
| 大屏线材、接收卡数量 | **必预列** |

写死常数（工控机 2580+200+200、接收卡 69/750、×1.03、÷0.68、三档总价）全部由 `scripts/calc.py` 计算，本岗和报价单岗都禁止再算。04 直接抄脚本 stdout 三张表。

## 计算

只做归类与选价：每条屏选定形态、长、高、屏数、数量、钢构归属（steel/hoop/body）、以及 03 里的单价，写成工作区里的 `lines.json`。面积、金额、价链都由脚本算。加载本 skill 后，用它返回的 base directory 运行包内脚本（控制台会话该目录一般是 `.skills/chuangdi-quote-price`）：

```bash
python3 <base>/scripts/calc.py < lines.json
```

禁止复制或改写 `scripts/calc.py`。stdout 原样抄进 `04-计价.md`。shell 只跑这一条。禁止在思考里逐行乘。

`lines.json` 形如：`{"control_base": 控制箱汇总, "chain": {"coef": 1.03, "div": 0.68, "card_n": 69, "card_d": 750, "ipc": 2980}, "lines": [{ ... }]}`。每行字段：

- `seq`（招标序号）、`name`（设备名称）、`qty`（招标数量）、`unit`（招标单位，仅备注）
- `form`（只能是：天棚屏、门架1米、门架1.5-2米、悬臂、车道屏1米、车道屏1×2米、车道屏2×2米、服务区、洞内屏、小型情报板）
- `length`、`height`（单幅长高）、`panels`（每套屏数，双幅=2）
- `side`（单面/双面）、`side_given`（是否招标写明面别）
- `module_w_mm`、`module_h_mm`、`module_price`（未定档填 `null`）
- `box_per_m2`、`power_price`、`power_per_m2`（无维护值填 `null`）
- `aux_per_m2`（汇总格有数）或 `aux_lines`/`aux_div`/`aux_plus`（汇总为空才滚）；`pack_per_m2` 同理
- `bracket_price`（无价填 `null`）、`bracket_unit`（套/平方，仅备注）
- `hoop_price`（无价填 `null`）
- `steel`：`"self"`（自己供，正常算支架）或 `"provided"`（交安已供整套钢构，支架抱箍为 0）
- `hoop`：`"self"`（正常算抱箍）或 `"provided"`（清单写含连接抱箍钢结构）
- `body`：立柱/支座/门架横梁本体的说明文本（如「含立柱」），只进「未计入钢构」清单，不影响支架数量；没有则空字符串

脚本自己算面积（长×高×屏数）与全部金额、价链、三档总价。**禁止手填 `area`。**

脚本 stdout 三张表原样抄入 04：分项收口（单套）、综合价链与三档报价、三档总价。禁止改任何一个数。

## 产出

只写 `04-计价.md`：脚本 stdout 三张表原样抄入（分项收口、综合价链、三档总价），再在表后补每条模组定档与钢构归属的备注。正文无工具名。

交稿前核对：面积=长×高×屏数；支架按形态公式（只有交安已供才为 0）；线材、接收卡有数；三档总价与脚本输出一致。

被打回时只改意见里点名的招标序号和字段。未点名的数保持原数，禁止整篇重写，禁止改算法。

## 红线

- 样例收口 × 面积代替本项目重算  
- 用样例「1㎡模组数量」当块数  
- 无定额且不按 2 只/㎡（缺维护值时的默认）  
- 无价表依据编造单价；03 未登记却回读表格补价；无毫米距却不 question 自选档位；招标技术条款已有毫米距却再 question / 标用户指定  
- 双幅再 × 屏数；未写面别却按双面；电源缺维护值却不用 2 只/㎡；含立柱/含支座/附着既有却把支架清成 0；交安已供整套钢构仍计支架  
- 控制箱汇总按面积折算或 ÷10；抱箍并进支架单价；抱箍数量乘面积  
- 因价目单位「套/平方」改支架数量算法  
- 控制系统分项之和与文内合计不一致  
- 在思考里逐行乘除；打回后改动未点名的数；创建其它岗位文件；签署/用印/建单
