# 报价计价（本项目收口重算）

产出 `04-计价.md`：本项目每平米/整屏收口分项底稿。对外正式件见 `chuangdi-quote-sheet`。  
程序不另写金额算法。

**禁止**「核算口径样例每平米收口 × 招标面积」代替重算。  
任务不附带大模组核算原表；规则只读本三件套与报价单 skill，禁止去翻原表。

## 输入三件套

1. **规格单价表**：模组/灯珠/套件单价；物理箱 SKU（本岗金额不走物理箱台数）。  
2. **核算口径表**：辅材 BOM；箱体/电源/支架/抱箍/控制箱价目；每平米收口结构（不把样例「1㎡模组数量」当项目块数）。  
3. **本 skill**：公式链与取整（形态/写死常数/总价见报价单 skill）。

只读本次任务附件；无附件则退回。见「供应商」表则停止并退回。附件价表按表内数字取用。

## 取整（统一）

数量须为整数且商为小数时：**向下取整**；算式备注写原始商与取整后值。  
适用于：模组块数、电源总只数（每㎡只数×面积时）、支架数量小数、接收卡数量。  
不适用于：元/㎡ × 面积（箱体、辅材、包材可保留面积小数）。

## 读哪份文件

### 规格单价表

表头第 4 行，数据自第 5 行。写明文件名、工作表、列、模组行数。不读「是否当前」「生效日期」。

### 核算口径表

| 工作表 | 用途 |
| --- | --- |
| 压铸铝辅材 / 铁箱辅材 | BOM → 辅材/包材元/㎡ |
| 箱体 | 综合单价（元/㎡）→ 进平方单价构成 |
| 电源 | 规格单价 |
| 支架 / 安装抱箍和螺钉 | 价目（报价单层支架/抱箍） |
| 控制箱 | 汇总 → 报价单「控制系统」每套（可预列） |
| 每平米收口 | 结构对照；不把样例「1㎡模组数量」当项目块数来源 |

## 模组

1. 亮度、面积、屏数、长高等以复核通过的抄录为准。  
2. **嵌入式 / 预告类：** 清单只给标志板外形、未给屏显尺寸 → **question**（建议项：按外形整板计面积；屏显尺寸由用户填写长×高；其他）；未答复前面积/模组按外形算并备注「屏显尺寸未确认，暂按外形」。  
3. **点间距：**  
   - 抄录或招标技术条款（含名称归并后）已有**毫米**数 → **直接用**，备注招标出处页；**禁止**标「用户指定」、**禁止**再 question。  
   - 仅像素密度或全书无毫米距（解析标「招标未给出毫米点间距」）→ 先 **question**，**必须列出建议项**：规格单价表「点间距_mm」去重档 + 可标一项「建议」；若有密度可备注换算参考（如 15625/㎡ ≈ 8mm），**不默认代选**；同一招标内相同密度不得无说明地选不同 P 档；拒答则模组金额留空；用户选定后备注「非招标原文」。  
4. **配比：** 招标已写（如 2R1G）→ 直接用。未写（户外常见）→ **question**（建议项：从价表该点距下已有配比列，如 2R1G / 2R1G1B / 其他）；拒答则按价表该点距唯一行，多行则留空待确认。  
5. 命中规格行：点间距相同，可再按配比、尺寸、批次收窄；灌胶决定单面/双面含税单价。多行列候选；零行写未命中。  
6. 单块面积 = (模组宽_mm/1000)×(模组高_mm/1000)。  
7. 整屏模组块数 = 屏面积合计 ÷ 单块面积，再 **向下取整**（不能整拼网格时同此规则，备注「未按整拼网格重排」）。  
8. **禁止**使用每平米收口样例「1㎡模组数量」作为块数来源。  
9. 含税单价_单面 = 灯珠合计 + 加工费 + 套件；双面再加灌胶加价。单元格空则金额留空。  
10. 模组金额 = 块数 × 面别含税单价。

## 箱体（元/㎡）

1. 按箱体材料/包边命中核算口径「箱体」价目行，取 **综合单价（元/㎡）**。  
2. 箱体金额 = 综合单价 × 屏面积合计（面积可带小数，不对「台数」取整）。  
3. 规格单价表「箱体单价」本岗不用于平方单价金额；交安已提供的钢结构不计。  
4. 价目空则该分项待确认。

## 电源

1. 单价：核算口径「电源」价目，按规格命中一行。  
2. 每平方米只数：优先读核算口径「每平米收口」中**已维护且非空**的「常规电源数量」（演示册有值则用该维护值；与模板其它列示例不一致时以该维护列为准）；任务说明给定则用说明。无维护值时 **question**，**必须列建议项**（如每㎡ 2 只；或本套总只数由用户填）；拒答则电源金额待确认。  
3. 若用每㎡只数×面积得总只数：结果 **向下取整**；电源合计 = 总只数 × 单价（或先算每㎡合计再×面积，取整规则在算式中写清）。

## 辅材 / 包材

1. 选表：压铸铝 → `压铸铝辅材`；铁箱/镀锌 → `铁箱辅材`。  
2. 汇总格为空（未计算的公式）时按明细滚：  
   - 压铸铝：行合计 = 含税单价×实际数量；再按「总计1平方辅料」「包材总计」「10㎡折1㎡」及表内常数（常有 +20）。  
   - 铁箱：先价税合计 = 含税单价×实际数量，再按表内 SUM/÷10/+常数滚元/㎡。  
3. 辅材金额 = 辅材元/㎡ × 面积合计；包材同理。写明工作表与标签。

## 支架 / 抱箍 / 钢构 / 控制系统（与报价单 skill 同口径）

安装形态清晰时：按报价单 skill 形态表算支架数量，单价取核算口径「支架」综合单价；数量小数向下取整；备注抄价目「单位」（套/平方）。  
形态不清：**question**，**必须列建议项**（候选取自报价单 skill 形态表：天棚/悬臂/门架1米/门架1.5-2米/车道/洞内/服务区等）。  

- **形态支架**计入；招标「含立柱」的立柱/门架横梁/标志板本体等 **04 标明未计、列入未计入钢构**，不 question「是否含在支架行」。交安已供钢构不计。  
- **双幅 / 每套多块屏**：先 **question**（不×屏数 / ×屏数 / 其他）；未答复按单幅公式并备注待确认；禁止静默 ×2。  
- **抱箍**：有「安装抱箍和螺钉」对应形态行则按套**另计**（与支架单价分列，禁止 230+68 揉成支架单价）；无行则 0 +「抱箍价目无行、未计」。须与报价单一致。  
- **控制系统（每套）：** 取「控制箱」汇总为每套底数（行名含「10 平方」也不 ÷10、不按面积折）；每条需报价预列金额；门架 1.5–2 / 服务区加价见报价单 skill。04 与报价单同数字。

收口内「安装支架选配」「安装抱箍和螺钉」有价目且本单需要计入平方单价时，从价目取值；否则在报价单层计支架/抱箍，04 中注明。

## 04 每条需报价必有分项

| 字段 | 要求 |
| --- | --- |
| 面积合计 | 必填算式 |
| 模组（单块面积、块数含取整、单价、金额） | 有则填 |
| 箱体（元/㎡、金额） | 有则填 |
| 电源（只数来源、取整、单价、金额） | 有则填；否则待确认/已 question |
| 辅材元/㎡、辅材金额 | 有则填 |
| 包材元/㎡、包材金额 | 有则填 |
| **本项目平方单价构成 / 收口小计** | 已填七项能加则加；缺项标明待确认 |
| 支架数量与单价、抱箍（若本步能算） | 可填，供报价单引用；口径同 skill |
| 控制系统（控制箱汇总±形态加价） | 可填，供报价单引用 |

写死常数与形态公式以 **报价单 skill** 为准。本岗可预列供下游：
工控机 `2580+200+200`；普通接收卡 ×**69**、点检 ×**750**；综合价相关项 ×**1.03**；比例 **0.68**。
线材：天棚/门架1米 `(长−10)×100`；门架1.5-2米 `(长−10)×150×高+(高−1)×300`；服务区 `长×高×50`；其余无则空。
接收卡数量：天棚/悬臂/门架/服务区 `(长÷2)×高`；车道屏与洞内 `高`；小型情报板 `1`（小数向下取整）。
控制系统：控制箱汇总（每套）；门架1.5-2 `+(高−1)×100+(长−5)×100`；服务区 `+(高−1)×300+(长−5)×200`。

## 产出

只写 `04-计价.md`。正文无工具名。每条含完整算式与取整备注。  
预列的支架/抱箍/控制系统须可被报价单原样引用（禁止 04 写「未含」而报价单全填这类分叉）。

## 红线

- 样例收口 × 面积代替本项目重算  
- 用样例「1㎡模组数量」当块数  
- 无定额且不 question 编造电源只数  
- 无价表依据编造单价；无毫米距却不 question 自选档位；招标技术条款已有毫米距却再 question / 标用户指定  
- 控制箱汇总按面积折算或 ÷10；抱箍并进支架单价；双幅静默 ×2  
- 创建其它岗位文件；签署/用印/建单
