# 报价计价（公式链 + BOM）

这是成本岗的**计价演算口径**（产出 `04-计价.md` 底稿）。对外正式件见 skill `chuangdi-quote-sheet`。  
**必须按本 skill 的公式链执行**；程序不另写一套金额算法。单价空着就留空，不补数，不挑最低价。

## Agent 输入三件套（缺一不可）

1. **规格单价表**（`规格单价表.xlsx`）：模组/灯珠/套件/箱体等**大件单价**。  
2. **核算口径表**（`核算口径表.xlsx`）：**辅材 BOM**（`压铸铝辅材` / `铁箱辅材`）+ **每平米收口**；**不是**又一份大件价目。  
3. **本 skill**：相对固定的**公式链**。BOM 明细与常数加价以表为准，人改表后以新表滚出。

协作里「读表」只登记结构；**算量算价与辅材必须在本岗按公式链 + BOM 做完并写出算式**。

大模组核算原 xls 是演算底稿，已拆进上面两份表；报价时不要再去 `docs/` 打开原件。

只读这次任务附件里的工作簿。没有附件就退回。工作簿里若有「供应商」表，停止并退回。

## 读哪份文件

### 规格单价表

表头在第 4 行，数据从第 5 行起。先写明文件名、工作表名、用了哪些列、模组有几行。不读「是否当前」「生效日期」。

### 核算口径表

| 工作表 | 用途 |
| --- | --- |
| 说明 | 分工说明 |
| 压铸铝辅材 | 逐项 BOM；汇总格滚出每平米辅材/包材 |
| 铁箱辅材 | 同上（铁箱/镀锌路径） |
| 每平米收口 | 按点间距×箱体材料核对 1㎡模组数量、电源数量；包材/辅材列公式引用 BOM |

若任务同时提交了 `规格单价表-演示.xlsx` / `核算口径表-演示.xlsx`，只能出现在标成「演示价」的对照里，不能写成正式报价。正式计价用无「-演示」后缀的文件。

## 怎么取行（大件）

1. 点间距、亮度、面积、屏数等以**复核通过**的抄录为准。抄录里没有毫米点间距的行，不取模组价格。
2. 模组价格表一行一个规格；单面/双面灌胶不拆行，同行有「含税单价_单面」「含税单价_双面」两列。取行时按点间距相同；成本岗若在核算模板里写了配比、尺寸、批次，再按这些列收窄。**灌胶不参与找行**，只决定取哪一列单价。
3. 命中一行才取价：核算模板「灌胶」为双面则用「含税单价_双面」，否则用「含税单价_单面」。命中多行就列出候选，不取最低价，金额留空。命中零行就写未命中。
4. 灯珠单价、加工费、套件单价、灌胶加价、箱体单价有空单元格时，金额留空，写明哪一列是空的。
5. **不要**用每平米收口表上的模组单价/箱体单价/电源单价列填正式价（整理时已留空）；大件只取规格单价表。

## 公式链（必须按序写进 04-计价）

在结果里逐步写出，便于复算：

1. **显示面积** = 宽 × 高（米）；以复核通过的抄录为准。  
2. **模组数量** = 显示面积 ÷ 单块模组面积 × 每套屏数 × 套数；除不尽则停下不四舍五入；双幅按抄录块数。  
3. **含税单价_单面** = 灯珠合计 + 加工费 + 套件单价；**含税单价_双面** = 单面 + 灌胶加价。  
4. 灯珠合计 = 各色数量 × 各色单价；套件合计 = 底壳 + 面罩数量 × 面罩单价 + 胶圈。  
5. **模组金额** = 模组数量 × 所取面别含税单价。  
6. **箱体数量/金额**按箱体外形同样处理；交安已提供的钢结构不计。  
7. 电源、接收卡：规格单价表无单价则只列数量、金额不计入。  
8. **辅材/包材**（见下节 BOM）→ 每平米金额 × 面积 × 屏数 × 套数。  

同一抄录、同一价格行、同一灌胶面别、同一 BOM 版本，按上式重算应得到同一金额。

### 辅材 / 包材（BOM → 元/㎡ → × 面积）

**不要写死单元格地址**（行号列号会随维护人增删明细而变）。先读本次附件里对应 BOM 表，按**语义**定位汇总，再取数。

1. **选表**：箱体为压铸铝 → `压铸铝辅材`；铁箱 / 镀锌钢板 → `铁箱辅材`。表名以附件实际为准（含说明页映射）。  
2. **认结构**：表头找「数量 / 含税单价 / 金额」等列；明细行是逐项 BOM；靠下或带公式的是**汇总区**，不是又一批料号。  
3. **定位每平米辅材**：在汇总区用行标签/说明文字找「总计」「1平方辅料」「1㎡辅材」一类结果；若另有「10㎡ / 10 平方共用」再「折 1㎡ / ÷10」行，一并计入；若汇总公式或同行写明常数加价（如 `+20`），以**表内公式/标注**为准，勿凭记忆写死。  
4. **定位每平米包材**：同样用「包材总计」「包材」等标签找汇总，与辅材分列计。  
5. **取不到已算汇总值**：按该表明细「数量 × 含税单价」逐项求和，再按表内已有折算行（如 10㎡→1㎡）折成元/㎡；折算规则以表为准。  
6. **写出依据**：在 `04-计价` 写清「工作表名 + 行标签/说明原文 + 实际单元格（读到时）+ 数值」，便于复算；禁止无 BOM 依据的辅料估算。  
7. **可选对照**：同点间距×箱体材料在「每平米收口」的「辅材」「包材」列若公式引用上述 BOM 汇总，可与本岗滚出值核对；不一致以 BOM 语义汇总为准并待确认。核算模板若仍有「每平方米辅料」列，同理。

### 与每平米收口核对

同一点间距、同一箱体材料在「每平米收口」有「1㎡模组数量」时，与按面积除出的每平米块数核对；不一致则待确认。
