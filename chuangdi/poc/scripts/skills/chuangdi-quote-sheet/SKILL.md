# 正式报价单

对外报价底稿。不定责、不盖章、不建单。空价写「待确认」，不补数。  
正文不出现工具名、置信度。

## 输入

- 上游：`01-解析`、`02-复核`、`04-计价`、`05-物料核对`
- 任务附件：招标 PDF（取项目名称、招标编号）
- 任务说明：是否要求导出 Word（docx）或 PDF  

`04-计价` 是演算底稿；本岗产出才是正式件。附件价表（含「-演示」文件名）按正式表使用，单价与金额写入正式栏。

## 对标招标

1. 只收录 `02-复核` 通过的需报价条目（本次不报价可单列，不进金额表）。  
2. 每一报价条目对应招标一览表一个序号项，名称用招标原文。  
3. 每条写明出处页码。  
4. 数量、单位与抄录一致。  
5. 价表无或单价空：保留该条目，单价与金额写「待确认」。  
6. 上游计价点间距为「用户指定 / 投标人选型」时：规格摘要可写该毫米数，**备注**写「点间距用户指定，非招标原文」。  
7. 不合并多个招标序号为无法回溯的一项。

## 按需：Word / PDF

仅当任务说明明确要求时生成。

### 优先：平台 Skill

| 用户要求 | 加载 Skill | 目标文件 |
| --- | --- | --- |
| Word / docx | `docx` | `报价单.docx` |
| PDF | `pdf` | `报价单.pdf` |

把 `报价单.md` 整理成该 Skill 的 JSON spec 并调用。内容与 md 一致。PDF 含中文时按 `pdf` Skill 配置 CJK 字体。

### Skill 不够时：工作区写代码

1. 在会话工作区编写转换脚本，依赖用工作区可安装的库  
2. 输入以 `报价单.md` 为准，输出 `报价单.docx` / `报价单.pdf`  
3. 留下脚本与产物；内容与 md 一致  

转换在 Agent Forge 任务工作区内完成。

## 红线

- 编造单价（无价表依据）  
- 无出处页码  
- 用户未要求时导出 Word/PDF  
- 签署建议、用印、建单
