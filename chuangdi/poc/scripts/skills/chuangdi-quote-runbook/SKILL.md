# 报价协作作业标准

不定责，不用印，不建单。无 MCP。只认任务附件与任务说明。

## 写法

指代招标内容用 **页码 + 招标序号 + 设备名称**。正文不出现工具名、参数名、置信度。

## 你只做自己那一步

角色说明会点名你要写入的文件。只写被点名的文件。

## 三件套

1. **规格单价表**：模组/灯珠/套件；物理箱 SKU 供核对  
2. **核算口径表**：辅材 BOM、箱体/电源/支架/抱箍价目、每平米收口结构  
3. **计价 / 报价单 skill**：本项目收口重算与形态/写死常数（非样例×面积）

读表岗登记规格表与核算口径各工作表（含四页价目与两辅材、每平米收口）。  
计价岗输出本项目分项收口底稿；报价单岗用本项目尺寸填全表头，**支架/线材/接收卡/工控机/69/750/1.03/0.68 一律照 skill 写死公式与数字**，禁止去翻原表或猜数。

**统一取整：** 块数/只数/支架数/接收卡数为小数时向下取整，备注原始商。  
BOM 汇总格读空：按明细滚出元/㎡。  
附件价表按表内数字取用。

## 解析与复核

产品范围以 skill `chuangdi-quote-scope` 为准（解析/复核必读）。  
常规品与定制品同一套后续计价/报价逻辑。  
整本无点间距时写「招标未给出」。

## 步骤

1. 解析 → `01-解析.md`  
2. 复核 → `02-复核.md`  
3. 读表 → `03-读表.md`  
4. 计价 → `04-计价.md`（本项目重算；缺距/缺电源定额/缺形态时 question）  
5. 物料核对 → `05-物料核对.md`  
6. 报价单 → `报价单.md`（仅需报价；全表头；按需 docx/pdf）  

## 红线

- 样例每平米收口 × 招标面积代替重算  
- 无算式报金额；跳过 BOM  
- 无价表编造单价；缺距不 question 自选档位  
- 报价单写入不报价名单或用非本项目尺寸的样例长宽  
- 去翻未上传的大模组核算原表；形态公式不按 skill 照读而另猜  
- 用户未要求时导出 Word/PDF；签署、用印、建单
