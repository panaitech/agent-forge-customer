# 报价协作作业标准

不定责，不用印，不建单。无 MCP。只认任务附件与任务说明。

## 写法

指代招标内容用 **页码 + 招标序号 + 设备名称**。正文不出现工具名、参数名、置信度。

## 调用 question（必遵）

建议项是工具参数 `options` 里的可点选项，不是题干里的一段清单。界面只渲染 `options`。写进 `question` 字符串的档位不会变成建议项。

每道题：

- `header`：不超过 30 字。  
- `question`：只写要决定的事。禁止在题干里逐条抄选项。  
- `options`：数组，每项 `{ "label": "短名", "description": "一句说明" }`。至少两项。来源是价表已有档位、形态表、或技术条款候选。  

有推荐时，该项放在 `options` 第一位，`label` 以「（建议）」结尾。不写进 label，界面上就没有建议项。不代选，等用户点选后再写入交付物。同一口径的多条屏合成一道题。

「暂不定档」可以是一项。不要另写「其他」，界面会自带自由输入。拒答或超时：按各岗 skill 把对应金额留空或写待确认，不编造。

## 你只做自己那一步

角色说明会点名你要写入的文件。只写被点名的文件。

## 三件套

1. **规格单价表**：模组/灯珠/套件；物理箱 SKU 供核对  
2. **核算口径表**：辅材 BOM、箱体/电源/支架/抱箍/控制箱价目、每平米收口结构  
3. **计价 / 报价单 skill**：本项目收口重算与形态/写死常数/三档总价（非样例×面积）

读表岗把两张表里**后续要用来算价的行**写成 `03-读表.md`，只写这一次。计价岗只读这份文档，禁止再打开表格。  
计价岗输出本项目分项收口底稿（含支架/抱箍/控制系统/线材/接收卡/三档总价，全部由 `scripts/calc.py` 算）；报价单岗**抄 04** 填平方单价与形态金额（含**抱箍数量/单价/合计三列**），本岗**不再计算任何金额**；禁止报价单岗重算形态或价链；禁止去翻原表。  
复核岗只核对 `01-解析.md` 里的原文片段，禁止再打开招标书。

**统一取整：** 块数/只数/支架数/接收卡数为小数时向下取整，备注原始商。  
BOM 汇总格读空：按明细滚出元/㎡。  
附件价表按表内数字取用。

## 读表：写成给下游用的结构

只读规格单价表与核算口径表。见「供应商」表则 `03-读表.md` 只写退回，不再摘行。不算本项目金额。

`03-读表.md` 用下面的节，每节一张表，数字与表内一致。空单元格写「空」。不要抄说明页、不要抄「是否当前」「生效日期」。

| 节 | 要摘的列 |
| --- | --- |
| 规格单价 · 模组 | 数据自第 5 行。点间距、配比、宽、高、灯珠合计、加工费、套件、灌胶加价、单面含税、双面含税、规格标识 |
| 规格单价 · 箱体 | 只摘规格标识。不摘来算平方单价的单价 |
| 压铸铝辅材 / 铁箱辅材 | 行名、含税单价、实际数量；汇总标签（总计1平方辅料、包材总计、10㎡折1㎡及常数）的格。汇总为空写「空」并保留明细 |
| 箱体 | 材料或包边、综合单价（元/㎡） |
| 电源 | 规格、单价 |
| 支架 | 名称、综合单价、单位 |
| 安装抱箍和螺钉 | 名称、综合单价、单位 |
| 控制箱 | 只写汇总金额一行，注明行名原文。不逐颗摘辅材 |
| 每平米收口 | 列名，以及「常规电源数量」的维护值。样例「1㎡模组数量」单独标「样例，禁止当项目块数」 |

**模组默认档：** 「规格单价 · 模组」表里，每个点间距选一行标「默认」（企业常用配比/芯片档），供计价岗在招标未写配比时取用。点间距只有一行就不用标。

## 解析与复核

产品范围以 skill `chuangdi-quote-scope` 为准（解析/复核必读）。  
常规品与定制品同一套后续计价/报价逻辑。  
点间距：招标技术条款有毫米距必须抄录并注出处；仅无毫米距时写「招标未给出毫米点间距」。章节名因标书而异，自行定位。

## 步骤

1. 解析 → `01-解析.md`  
2. 复核 → `02-复核.md`  
3. 读表 → `03-读表.md`  
4. 计价 → `04-计价.md`（脚本算全部金额与三档总价；仅无毫米距或形态不在表内时 question，答复写入备注）  
5. 报价单 → `报价单.md`（仅需报价；全表头；抄 04 的价链与三档总价；按需 docx/pdf）  

## 红线

- 样例每平米收口 × 招标面积代替重算  
- 无算式报金额；跳过 BOM  
- 无价表编造单价；无毫米距不 question 自选档位；招标技术条款已有毫米距却标用户指定  
- 调用 question 时不填 `options`，或把档位只写在题干里  
- 报价单写入不报价名单或用非本项目尺寸的样例长宽；无三档总价  
- 报价单岗重算支架/抱箍/控制系统/价链等导致与 04 不一致；无抱箍三列  
- 计价岗再打开表格；复核岗或报价单岗再打开招标书  
- 主管再问计价岗已经写入 04 备注的口径；计价岗对双幅、面别、电源缺档再次提问  
- 计价岗因价目单位「套/平方」改支架数量；含立柱/含支座/附着既有却把支架清成 0；交安已供整套钢构仍计支架；控制系统两处合计不一致；打回后改未点名的数  
- 去翻未上传的大模组核算原表  
- 用户未要求时导出 Word/PDF；签署、用印、建单
