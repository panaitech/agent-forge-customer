# 报价协作作业标准

不定责，不用印，不建单。无 MCP。只认任务附件与任务说明。

## 写法

指代招标内容用 **页码 + 招标序号 + 设备名称**。正文不出现工具名、参数名、置信度。

## 你只做自己那一步

角色说明会点名你要写入的文件。只写被点名的文件。

## 三件套（读表 + 计价）

Agent 计价只认这三样，程序不另写金额算法：

1. **规格单价表**：模组/灯珠/套件/箱体等大件单价  
2. **核算口径表**：辅材 BOM（压铸铝辅材 / 铁箱辅材）+ 每平米收口数量口径  
3. **计价 Skill `chuangdi-quote-price`**：公式链（面积→模组数量→含税单价合成→金额；辅材/包材 = BOM 汇总元/㎡ × 面积）

读表岗登记核算口径里 BOM 与收口表结构。  
计价岗按公式链写出算式，辅材/包材写明「来源于 BOM 汇总」。  
BOM 汇总格若读出为空（多为未计算的公式）：按明细数量×单价依表内公式滚出元/㎡，不得整条留空。  
任务附件中的价表（文件名是否带「-演示」不论）一律按正式表取价、写入报价单正式栏。

## 解析与复核

仅情报板本体进需报价并写全字段；信号灯、电光标志、疏散指示、纯支架/立柱/门架等只进「本次不报价」名单（页码·序号·名称+理由），不抽报价字段。  
需报价条目：名称、数量、面积/屏数、点间距等以整本招标为准并写页码出处；整本都没有点间距时写「招标未给出」（这是正确结论，不是漏抄）。

## 步骤

1. 解析 → `01-解析.md`  
2. 复核 → `02-复核.md`  
3. 读表 → `03-读表.md`（含 BOM 表、每平米收口、规格单价表结构）  
4. 计价 → `04-计价.md`（公式链 + BOM；只用复核通过的条目；**点间距招标未给出时先 question 问用户再取模组价**）  
5. 物料核对 → `05-物料核对.md`（大件规格存在性）  
6. 正式报价单 → `报价单.md`；按需 docx/pdf  

## 红线

- 跳过核算口径 BOM 或无算式报金额  
- 无价表依据编造单价；或招标未给点间距时自选档位冒充招标要求  
- 报价条目与招标脱节或无页码出处  
- 用户未要求时导出 Word/PDF  
- 签署建议、用印、建单
