# 报价协作作业标准

不定责，不用印，不建单。无 MCP。只认任务附件与任务说明。

## 写法

指代招标内容用 **页码 + 招标序号 + 设备名称**。正文不出现工具名、参数名、置信度。

## 调用 question（必遵）

凡使用 **question** 工具向用户确认时：

1. **必须提供建议项**（可勾选/可点选的选项列表），不得只抛开放问题。  
2. 建议项来自：价表已有档位、skill 形态表、招标技术条款候选、或确认稿常见口径；每项一行写清含义。  
3. **不默认代选**：可标注「建议」或推荐某一项，但须等用户答复后再写入计价/报价单。  
4. 拒答或超时：按各岗 skill 将对应金额留空/待确认，不编造。

## 你只做自己那一步

角色说明会点名你要写入的文件。只写被点名的文件。

## 三件套

1. **规格单价表**：模组/灯珠/套件；物理箱 SKU 供核对  
2. **核算口径表**：辅材 BOM、箱体/电源/支架/抱箍/控制箱价目、每平米收口结构  
3. **计价 / 报价单 skill**：本项目收口重算与形态/写死常数/三档总价（非样例×面积）

读表岗登记规格表与核算口径各工作表（两辅材、箱体、电源、支架、抱箍、**控制箱**、每平米收口）。  
计价岗输出本项目分项收口底稿（含支架/抱箍/控制系统预列）；报价单岗**抄 04** 填平方单价与形态金额（含**抱箍数量/单价/合计三列**），本岗只算工控机/69/750/1.03/0.68 与三档总价；禁止报价单岗重算形态；禁止去翻原表。

**统一取整：** 块数/只数/支架数/接收卡数为小数时向下取整，备注原始商。  
BOM 汇总格读空：按明细滚出元/㎡。  
附件价表按表内数字取用。

## 解析与复核

产品范围以 skill `chuangdi-quote-scope` 为准（解析/复核必读）。  
常规品与定制品同一套后续计价/报价逻辑。  
点间距：招标技术条款有毫米距必须抄录并注出处；仅无毫米距时写「招标未给出毫米点间距」。章节名因标书而异，自行定位。

## 步骤

1. 解析 → `01-解析.md`  
2. 复核 → `02-复核.md`  
3. 读表 → `03-读表.md`  
4. 计价 → `04-计价.md`（本项目重算；无毫米距/缺电源定额/缺形态时 question）  
5. 物料核对 → `05-物料核对.md`  
6. 报价单 → `报价单.md`（仅需报价；全表头；三档总价；按需 docx/pdf）  

## 红线

- 样例每平米收口 × 招标面积代替重算  
- 无算式报金额；跳过 BOM  
- 无价表编造单价；无毫米距不 question 自选档位；招标技术条款已有毫米距却标用户指定  
- 调用 question **不提供建议项**（只抛开放问题）  
- 报价单写入不报价名单或用非本项目尺寸的样例长宽；无三档总价  
- 报价单岗重算支架/抱箍/控制系统等导致与 04 不一致；无抱箍三列  
- 去翻未上传的大模组核算原表  
- 用户未要求时导出 Word/PDF；签署、用印、建单
