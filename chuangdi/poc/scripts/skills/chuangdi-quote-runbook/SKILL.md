# 报价协作作业标准

不定责，不用印，不建单。无 MCP。只认任务附件与任务说明。

## 你只做自己那一步

角色说明会点名你要写入的文件。只写被点名的文件。

## 三件套（读表 + 计价硬性）

Agent 计价只认这三样，**程序不另写金额算法**：

1. **规格单价表**：模组/灯珠/套件/箱体等**大件单价**  
2. **核算口径表**：**辅材 BOM**（压铸铝辅材 / 铁箱辅材）+ **每平米收口**数量口径；不是第二本大件价目  
3. **计价 Skill `chuangdi-quote-price`**：**公式链/公式骨架**（面积→模组数量→含税单价合成→金额；辅材/包材 = BOM 汇总元/㎡ × 面积）

读表岗必须登记核算口径里 BOM 与收口表结构。  
计价岗必须按公式链写出算式，辅材/包材写明「来源于 BOM 汇总」，禁止拍脑袋辅料。  
演示稿（`*-演示.xlsx`）只能对照，不得进正式报价栏。

## 报价视角（解析 + 复核）

清单侧支撑：名称对标招标、数量单位、面积/屏数、点间距与显示要求、安装形态、出处。招标没有的留空并标明。

## 步骤

1. 解析 → `01-解析.md`  
2. 复核 → `02-复核.md`  
3. 读表 → `03-读表.md`（含 BOM 表、每平米收口、规格单价表结构）  
4. 计价 → `04-计价.md`（公式链 + BOM 路径；只用复核通过的行）  
5. 物料核对 → `05-物料核对.md`（大件规格存在性，非逐颗辅材 BOM）  
6. 正式报价单 → `报价单.md`；按需 docx/pdf  

## 红线

- 禁止跳过核算口径 BOM、禁止无算式报金额  
- 禁止演示价写入报价单正式栏  
- 禁止报价行与招标脱节或无出处硬填  
- 禁止用户未要求时导出 Word/PDF  
- 禁止签署建议、用印、建单  
- 禁止工具名、参数名、置信度
