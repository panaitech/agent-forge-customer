# 报价数据整理模版填写说明

配套文件：`报价数据整理模版.xlsx`。  
从客户原表整理出的结果：

| 文件 | 来源 | 管什么 |
| --- | --- | --- |
| `数据/规格单价表.xlsx` | `docs/材料成本.xlsx` | 模组/灯珠/套件/箱体等**规格与单价**（正式） |
| `数据/核算口径表.xlsx` | `docs/大模组核算….xls` | **辅材 BOM** + **每平米数量口径**（正式；不是又一份模组价目） |
| `数据/规格单价表-演示.xlsx` | 自 `规格单价表-原表整理.xlsx` 复制填模拟价 | POC 用，**非客户成本** |
| `数据/核算口径表-演示.xlsx` | 自核算口径表复制填模拟价 | POC 用，**非客户成本** |

Agent 报价三件套：规格单价表 + 核算口径表 + `poc/skills/报价计价`。大模组核算原 xls 是造价/应标演算底稿，不随任务上传。

读源过程见 `数据/读表记录.md`。原表计算链见 `方案/核算原表计算规则分析.md`。  
**核算口径表怎么维护**见 [方案/核算口径表维护说明.md](../方案/核算口径表维护说明.md)。

蓝色字是要填的数。绿色字是公式，不要手改。模版第 5 行黄色是示例。演示工作簿由 `poc/seed_demo.py` 生成，黄底为模拟填入价。**除演示副本外，不得新增原表不存在的模组规格。**

## 谁维护

成本维护人填写：灯珠单价、套件、模组规格和加工费、箱体单价；以及核算口径表里的辅材 BOM 明细。报价的人不改这些数，只在报价结果里确认被标出的行。

供应商名称只写在「供应商」表。报价不读这张表。

## 调价怎么做

同一条件只保留一行有效价。灯珠按批次；套件按点间距加工艺；模组按名称、点间距、配比、尺寸、批次；箱体按箱体名称。单面/双面灌胶同属一行，不拆两行。

调价时直接改该行单价。不另起历史行，不维护「是否当前」「生效日期」。

辅材改价或改用量：改核算口径表「压铸铝辅材 / 铁箱辅材」对应行；汇总格与每平米收口「辅材/包材」公式会跟变（在 Excel 中打开后可见）。

## 规格单价表各列：从哪里读

源文件：`docs/材料成本.xlsx`。整理脚本：`poc/整理原表.py`。

### 灯珠单价

| 列 | 来源 |
| --- | --- |
| 灯珠批次 | 由模组表灯珠单价公式指向推断：`灯价格!A3`→批次-510，`灯价格!A7`→批次-310 |
| R/G/B 单价 | 原表有数字则转入；无数留空（不填 0），维护人可补 |
| 备注 | 整理时清空；需要说明时再手填 |

### 套件单价

| 列 | 来源（工作表「套件」） |
| --- | --- |
| 点间距_mm、工艺 | 第 1 列名称解析（如「P10.416 贴片」） |
| 底壳/面罩/胶圈单价 | 原表有数字则转入；无数留空 |
| 套件合计 | 绿色公式：底壳＋面罩数量×面罩单价＋胶圈 |

### 模组价格（含「名称」列）

源工作表：`普通模组价格5034B`、`普通模组价格16289`、`250-500模组价格5034`、`250-500模组价格16289`。  
表头在第 2 行。普通表左右两块：左块起点列 2（批次-510），右块起点列 21（批次-310，第 4 行名称非空才读）。250-500 表只有左块（批次-310）。  
同表下方还可再挂驱动分段（标题如 `普通模组价格5124-310-F5`）：规格行仍读入，「驱动芯片」写为文本。

| 整理表列 | 原表列（相对块起点） | 说明 |
| --- | --- | --- |
| 名称 | 名称（起点列） | 原样保留，如 `P33.33` |
| 点间距_mm | 由名称解析 | 去掉前缀 P |
| 配比 | 配比（+1） | 如 4R2G |
| 灯珠芯片 | 芯片（+2） | |
| 亮度_cd每平方米 | 亮度（+3） | 从 `15000CD/㎡` 取数字 |
| 模组宽_mm、模组高_mm | 尺寸（+4） | |
| 驱动芯片 | 聚积芯片（+5） | 统一文本 |
| 色品 | 色品坐标（+6） | 规范为 黄色/白色/黄白 |
| 灯珠批次 / 工艺 | 块所属批次；工艺固定「贴片」 | |
| R/G/B 数量 | +7/+8/+9 | 数字或算术公式 |
| 含税单价_单面 / _双面 | 绿色公式 | 双面＝单面＋灌胶加价 |
| 加工费、灌胶加价 | 有数字则转入；无数留空 | |

### 箱体单价

源：工作表「箱体单价」第 2 行表头。含税单价有数字则转入。

### 核算模板

默认选型快捷表，**不存模组单价**。灌胶列只决定取单面价还是双面价。「每平方米辅料」若仍保留，须等于核算口径表 BOM 滚出的辅材+包材；不一致以 BOM 为准。

## 核算口径表：从哪里读

源文件：`docs/大模组核算2026.06.16.xls`（先转 xlsx，保留公式）。

| 工作表 | 来源 | 内容 |
| --- | --- | --- |
| 说明 | — | 三件套分工 |
| 压铸铝辅材 | 1压铸铝平方辅材 | 逐项 BOM；F56 / F60 / E80 等汇总公式 |
| 铁箱辅材 | 1铁箱平方辅材 | 逐项 BOM；E58 / E63 等 |
| 每平米收口 | 1平方大模组屏体核算 | 点间距×材料、1㎡模组数量、电源数量；包材/辅材公式引用辅材表。**模组/箱体/电源单价列留空** |

不转入：屏体清单样例层、原箱体/电源价目表（避免与规格单价表双源）。

## 各表怎么填（维护人）

### 规格单价表

按列填灯珠、套件、模组、箱体。绿色公式不要手改。

### 核算口径表 BOM

改数量或小件单价后，在 Excel 中确认汇总格与每平米收口「辅材」「包材」列跟变。公式骨架不要拆；常数加价（如 +20）改后同步计价 skill。

### 供应商

仅内部留底，报价不读。

## 示例行核对（模版演示，非创迪成本）

模版示例若未被改过，打开后应看到：

- 套件合计 17
- 模组含税单价_单面 92.6；含税单价_双面 95.6
- 核算模板示例灌胶=双面时，当前模组含税单价 95.6；当前箱体含税单价 800

这些数只说明表间勾稽。换成真实单价后会变。
