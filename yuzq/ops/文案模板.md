# 合同助手会话文案模板

依据：`docs/方案/企微合同助手用户场景与交互设计方案.md` §8。  
实现：`wecom-bridge/app/messages/templates.py`。

| 场景 | 模板要点 |
| --- | --- |
| 受理 L0 | 已收到《{文件名}》，任务号 {任务号}。正在提取… |
| 进度 L1 | 任务 {任务号}：{阶段}。 |
| 待办 | 任务 {任务号} 待确认… + 去确认链接 |
| 草稿完成 | 草稿已确认。请按公司流程提交会审。 |
| 拒绝 | 暂无权限或已停用，联系管理员。 |
| 失败 | 未能完成：{原因}。保留任务号。 |

禁止默认推送：推理过程、工具名、原始 JSON、调试置信度。
