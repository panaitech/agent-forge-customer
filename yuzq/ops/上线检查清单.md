# 雨中情合同助手 · 上线检查清单（S0）

依据：`docs/方案/企微身份映射与对接服务设计方案.md` §8.1。

## 1. 企业微信

- [ ] 自建应用「合同助手」已创建，AgentId / Secret 已记录
- [ ] 回调 URL 指向 Bridge：`https://<host>/wecom/callback`
- [ ] Token、EncodingAESKey 与 Bridge `.env` 一致；GET 校验通过
- [ ] 应用可见范围已划定试点人员/部门
- [ ] 通讯录只读或成员变更权限已申请（或启用过渡导入）

## 2. Agent Forge

- [ ] 目标租户 `AF_TENANT_ID` 已创建
- [ ] Bridge 机器账号可用（Basic Auth）；密码未分发给业务人员
- [ ] `AGENTFORGE_IDENTITY_MAP` 为 Bridge 用户配置 `"delegate":true`（及正确 tenant）
- [ ] 已 inject「雨中情-合同录入」协作；`AF_INTAKE_TEAM_ID` 或名称可解析

## 3. Bridge

- [ ] `WECOM_CORP_ID` ↔ `AF_TENANT_ID` 已写入配置
- [ ] 默认角色、例外表、ticket 密钥已配置
- [ ] `AF_INTAKE_TEAM_NAME` / `AF_INTAKE_TEAM_ID` 已核对
- [ ] 首次全量同步或 `import_members` 已执行；抽样 `owner_id` 符合 `wecom:{corp}:{userid}`
- [ ] `/healthz` 正常；`DRY_RUN_*` 在生产关闭
- [ ] 生产以 Docker 部署：`CLOUD_HOST=... bash wecom-bridge/docker/tencent/deploy.sh`
- [ ] nginx 已接入 `docker/tencent/gateway/wecom-bridge.conf`；回调为 HTTPS

## 4. 端到端

- [ ] 可见成员发送文件 → 收到含任务号的受理消息
- [ ] 随后收到 L1 阶段消息（收件 / 提取 / 匹配 / 草稿）
- [ ] 控制台可见对应该 `owner_id` 的**协作运行**（非空会话 + 一句 prompt）
- [ ] 出现 HITL 后收到「去确认」；链接打开 `/teams/runs/:runID`（仍须控制台登录）
- [ ] 录入协作 delivered 后收到草稿完成通知
- [ ] 不可见/禁用成员无法建任务
