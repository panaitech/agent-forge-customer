## 4. 行业环境

### 4.1 下游需求：新建端持续收缩（权威数据）

【事实】国家统计局《2026 年 1—9 月份全国房地产市场基本情况》（2026-10-19，[原文](https://www.stats.gov.cn/sj/zxfb/202610/t20261019_1965615.html)）：

- 全国房地产开发投资 53364 亿元，同比 **-20.6%**
- 房屋新开工面积 34031 万平方米，同比 **-24.9%**（住宅 -25.4%）
- 房屋竣工面积 23271 万平方米，同比 **-25.1%**
- 新建商品房销售面积 56483 万平方米，同比 **-13.2%**；销售额 53799 亿元，同比 **-13.9%**
- 房地产开发企业到位资金 56813 亿元，同比 **-21.6%**（国内贷款 -33.1%）
- 反向亮点：二手房交易网签面积 61746 万平方米，同比 **+10.7%**

【推断】对防水企业的三层传导：

1. **量的收缩**：新开工决定 1—2 年后的防水施工需求，-24.9% 的新开工意味着新建防水市场仍在缩量。
2. **结构迁移**：增量从民营房企新建转向①央国企/政府投资的基建与市政（轨交、高铁、机场、场馆——恰是该公司案例集中的领域）、②存量房修缮翻新（二手房网签 +10.7% 是需求侧信号）。
3. **现金流压力**：到位资金 -21.6%、国内贷款 -33.1%，意味着甲方付款能力下降 → 供应商面临**账期拉长、票据结算、以房抵款**等条款，合同评审与回款管理的重要性上升。
   （以上为分析推断，非企业披露。）

### 4.2 竞争格局

- 【事实·二手】行业研究摘要称：2024 年中国建筑防水材料行业产量约 34.73 亿平方米；行业前十企业合计份额约 32.6%，其中东方雨虹约 14.8%、科顺约 9.3%，凯伦、北新建材等紧随。来源：360 快传/新浪财经行业研究摘要（二手，2025-09 至 2026-01 期间发布；**数据口径与原始出处待核**）。
- 【推断】格局为"一超多强 + 长尾分散"：头部（东方雨虹、科顺、北新、凯伦、三棵树等）以品牌+集采入围+全国产能取胜；区域型/专业型企业（如本客户）靠**区域产能半径 + 央国企集采资质 + 标杆工程**守住份额。价格战与集采压价是常态。
- 【未检索到公开来源】雨中情自身的市场份额、营收规模排名（行业协会口径的完整榜单未见公开可引版本）。
